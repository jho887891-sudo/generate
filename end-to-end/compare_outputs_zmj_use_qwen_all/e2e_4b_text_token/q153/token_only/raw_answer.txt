【结论】当前样本应优先把高速行程与射料结束位置放在一起判断，当前主导风险更偏向高速充型阶段的卷气风险。

【溯源分析】
1. 视觉层把高速行程= 205 和射料结束位置 748 作为区域证据，说明当前判断应关注高速充型路径和压射室/浇道/浇口的稳定。高速行程决定金属液进入型腔的速度和前沿，射料结束位置决定高速切换后金属液的稳定状态。两个参数共同变化时，更容易判断缺陷是来自高速充型不稳，还是来自压室/浇道/浇口的过渡问题。
2. 从高速速度= 3.65、高速行程 = 205、高速时间 = 46、建压时间 = 114、压射压力 = 316、铸造压力 = 926 这条参数链看，高速速度、高速行程和建压时间共同决定金属液进入型腔后的过渡状态。高速速度过高会把金属液带得过急，高速行程过长会把缺陷前移；建压时间短时压力传递不稳，建压时间长时容易把压力提前传递到金属液上。三者共同决定金属液进入型腔后的前沿稳定和排气状态。
3. 射料结束位置是判断高速切换后状态的直接依据。位置靠前说明金属液进入型腔较早，位置靠后说明高速切换后金属液前沿不稳定。当前样本把高速行程和射料结束位置作为共同判断依据，比只看单一参数更准确，也更容易把高速充型风险与后续压力传递分开。

【建议方向】
1. 先固定浇口、浇道和压射室状态，单独观察高速行程与射料结束位置的变化，确认缺陷是否随高速或压力变化而集中。
2. 复核时应把高速行程与高速时间、建压时间、铸造压力和射料结束位置同时看作变化指标，判断参数调整是否带来稳定改善。
3. 选择同料号、同模次或相近工况样本对照，观察高速行程变化时，缺陷分布是否同步变化。
