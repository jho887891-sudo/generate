四、检索文本：
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 局部挤压销: 在油孔处增加局部挤压销，或增加冷却水道。改变油孔位置，避开热节。若油孔是通孔，可考虑在另一侧增加补缩。
- 气体: 油污遇热挥发产生气体，进入型腔形成气孔。需保持分型面清洁，避免润滑剂过量。使用耐高温油脂。
- 内浇口速度: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 加强冷却: 分散性缩孔通常由整体补缩不足引起，如铸造压力过低、料饼太薄、铝液温度过高导致整体凝固慢，使铸件各处都有微小缩松。集中性缩孔则由局部热节补缩失效引起，如厚大区域浇口凝固过早、局部压力传递受阻。前者需整体调整参数，后者需针对局部优化（如加强冷却、增加挤压销）。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 冷隔: 硅含量影响合金流动性。高硅铝合金流动性好，有利于排气，减少卷气孔；但硅含量过高易产生集中缩孔。低硅合金流动性差，易产生冷隔和分散气孔。需根据铸件结构选择合适的合金。
- 填充时间延长: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 氢气在凝固时析出: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
