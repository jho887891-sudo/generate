四、检索文本：
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 集中气孔: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 铸造压力: 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 圆形: 含氢量升高会导致气孔数量显著增加，直径略有增大，分布从稀疏变为密集，厚大区域出现簇状气孔。气孔形态仍保持圆形，但边界可能因相互连接而模糊。
- 含氢量升高: 含氢量升高会导致气孔数量显著增加，直径略有增大，分布从稀疏变为密集，厚大区域出现簇状气孔。气孔形态仍保持圆形，但边界可能因相互连接而模糊。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 夹杂: 静置时间过长，铝液可能重新吸氢，尤其是环境湿度高时，气孔增加。同时氧化物可能下沉或上浮，若浇注时卷入，成为夹杂。精炼后应在合理时间内使用，否则需重新除气。保温炉需加盖覆盖剂。
- 涡流卷气: 连接处流动速度突变，易产生涡流卷气。同时厚壁处气体可能向薄壁处逸出。需优化过渡圆角，使流动平稳。调整高速速度，避免湍流。
- 厚大区域出现簇状气孔: 含氢量升高会导致气孔数量显著增加，直径略有增大，分布从稀疏变为密集，厚大区域出现簇状气孔。气孔形态仍保持圆形，但边界可能因相互连接而模糊。
