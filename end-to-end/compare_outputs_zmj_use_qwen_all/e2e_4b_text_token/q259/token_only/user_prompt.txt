四、检索文本：
- 金属液从慢速到高速的过渡平稳性: 比值决定金属液从慢速到高速的过渡平稳性。比值不当易在切换点产生卷气。一般推荐慢速临界速度以下，高速速度根据浇口面积计算，确保切换时金属液已到达内浇口且无波动。通过模拟或经验优化比值可减少气孔。
- 缩孔: 型芯冷却不足，局部过热，成为热节，产生缩孔。同时型芯易变形。需加强型芯冷却，如使用螺旋水道或点冷却。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 提高铸件致密度: 热处理加热时，缩孔周围组织软化，内部气体膨胀，可能导致缩孔扩大。若缩孔与表面连通，可能鼓泡。根本原因是原始缩孔严重。需提高铸件致密度，或调整热处理工艺（如降低温度、缩短时间）。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 除气: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 加强除气: 锌含量升高，合金熔点降低，流动性改善，但吸氢倾向增加，气孔可能增多。尤其是在高湿度环境下。需加强除气，并控制锌含量在合金标准内。对于高锌合金，需特别注意熔炼工艺。
- 最后填充区: 模拟软件可设置不同高速起点，观察流动前沿。找到使最后填充区位于溢流槽且无卷气的起点。同时检查浇口处是否先充满。
- 避免气体滞留: 油孔处常有润滑油残留，遇热挥发产生气体。需清洗油孔，或改用耐高温润滑剂。同时，优化该区域排气，避免气体滞留。
- 缩孔集中: 若气孔多且分散，缩孔集中，则气孔为主，需先除气；若缩孔大且位于热节，气孔少，则缩孔为主，需加强补缩。通过分析位置、形态可判断，并针对性处理。
