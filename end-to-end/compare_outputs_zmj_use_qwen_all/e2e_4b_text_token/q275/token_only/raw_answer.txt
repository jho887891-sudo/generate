【结论】当前样本应优先把牙孔区域作为异常起点，同时关注一般区域的数量分布作为补充参考。牙孔区域本身对局部排气和补压要求更敏感，若极值突出，说明局部气孔风险可能高于一般分布，但一般区域分布可判断是否为放大规模或系统性风险放大前兆。

【溯源分析】
1. 区域证据描述一般区域分布和牙孔区域极值，一般区域看数量规模，牙孔区域看单点极值。一般区域数量多，一般区域分布稳定；牙孔区域单点极值突出，说明该位置更容易受高速充型卷气、补压不足或局部排气不畅影响。
2. 参数链为高速速度= 建压时间. 压射压力. 铸造压力. 压射充型. 金属液进入. 低压阶段. 低压补压. 金属液进入。本题关注高速速度对高速行程、高速时间、建压和铸造压力的共同影响。高速速度决定高速充型阶段的卷气强度，若高速行程或高速时间不足，金属液前沿不稳，容易把气体带入型腔；若高速切换不及时，后续建压和补压会更难建立。
3. 区域风险不能只看极值，还要看参数链是否稳定。牙孔区域极值突出时，应把局部排气、高速切换和补压一致性作为比一般分布更优先的风险源。

【建议方向】
1. 先隔离牙孔区域样本，复核高速行程、高速时间、建压时间和铸造压力是否同步变化。
2. 用同料号、同模次或相近工况样本对照，观察极值是否集中，参数变化是否一致。
3. 后续验证应关注参数调整后，一般区域数量是否下降，同时观察牙孔区域极值是否收敛。
