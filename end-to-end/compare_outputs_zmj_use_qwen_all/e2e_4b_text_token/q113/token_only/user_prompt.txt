四、检索文本：
- 培训重点：气孔边缘光滑、圆形，缩孔边缘锯齿状、不规则。气孔颜色均匀，缩孔深浅不一。气孔分散，缩孔集中在热节。结合铸件结构判断，厚大区域多缩孔，薄壁区多气孔。多看图对比。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 不规则: 气孔边缘光滑、形状规则（圆形或椭圆形），颜色均匀；缩孔边缘不规则、树枝状，颜色深浅不一（因密度变化）。有时需结合缺陷位置判断：热节区多为缩孔，分散区多为气孔。
- 缩孔: 型芯冷却不足，局部过热，成为热节，产生缩孔。同时型芯易变形。需加强型芯冷却，如使用螺旋水道或点冷却。
- 夹杂: 剥落处粗糙，易粘铝，脱模时可能拉伤，形成气孔或冷隔。同时剥落物可能进入型腔成为夹杂。需定期检查模具表面，及时修复或重氮化。
- 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高速行程: 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
- 气孔边缘光滑、形状规则，颜色均匀；缩孔边缘不规则、呈树枝状或锯齿状，颜色深浅不一。气孔多分散，缩孔多集中在热节区。结合位置可准确判断。
- 预热镶件: 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
