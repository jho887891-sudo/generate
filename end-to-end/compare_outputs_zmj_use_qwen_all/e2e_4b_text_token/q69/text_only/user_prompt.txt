四、检索文本：
- 细化晶粒: 钪是稀有元素，可细化晶粒，提高性能，但对气孔无直接作用。成本高，很少用。
- 投影面积: 高速行程主要影响填充顺序，与投影面积无直接关系。但投影面积大的铸件通常需要更长的填充时间，因此高速行程可能较长。需根据浇注系统设计来确定高速起点。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 优化补缩: 根本原因是厚大区域是热节，凝固速度最慢。在凝固过程中，体积收缩需要补缩，如果补缩压力不足或补缩通道不畅，就会形成缩孔。同时，最后凝固的区域也是气体析出聚集的地方。因此，厚大区域容易同时出现缩孔和气孔，形成复合缺陷。解决思路是加强冷却、优化补缩和排气。
- 除气: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 补缩不足: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 优化浇口: 镶件预热可减少温差，避免局部热节。同时，在镶件周围增加挤压销，或优化浇口，使压力能传递到。也可改变镶件设计，使其更易补缩。
- 卷气形成气孔: 高速起点过早，金属液过早高速填充，卷气形成气孔；同时高速起点过早导致慢速行程缩短，铝液在压射室停留时间短、温度高，厚大区域凝固慢、收缩大，若增压不及时则产生缩孔。需优化高速起点，使金属液在到达内浇口时开始高速，平衡卷气和温降。
