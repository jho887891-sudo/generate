四、检索文本：
- 高速起点: 高速行程与浇口厚度无关，但浇口厚度影响补缩，间接影响高速起点的选择。厚浇口允许稍晚高速，因补缩通道持久。
- 料饼厚度: 射料结束位置通过料饼厚度影响整体致密度。如果料饼太薄，铸件疏松，焊接区域也可能疏松，焊接时气体逸出形成气孔。如果料饼合适，压力传递好，焊接区域致密，气孔少。因此，保证合适的结束位置有助于焊接质量。
- 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 流动性: 铁含量高会形成脆性相，降低流动性，使补缩困难，缩孔倾向增加。同时，铁相可能堵塞补缩通道。但适量铁可减少粘模。需控制在合理范围。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 硅含量升高，流动性改善，凝固范围变窄，补缩性能提高，缩孔倾向减小。共晶合金体积收缩率也较低。因此，提高硅含量有助于减少缩孔，但需注意过共晶硅粗大反而降低性能，控制在共晶点附近最佳。
- 高速行程: 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
