四、检索文本：
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 优化: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 流动性: 铁含量高会形成脆性相，降低流动性，使补缩困难，缩孔倾向增加。同时，铁相可能堵塞补缩通道。但适量铁可减少粘模。需控制在合理范围。
- 气体: 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 缩孔: 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 慢速卷气: 慢速速度调慢减少了压射室内的卷气，使进入型腔的初始气体总量减少。焊接区域作为铸件的一部分，其含气量也随之降低，因此焊接时气孔减少。这说明该焊接区域的气孔主要来自慢速卷气。
- 卷气机会增加: 慢速行程影响铝液在压射室内的停留时间和卷气量。如果慢速行程过长，铝液降温多，卷气机会增加，焊接区域可能因含气量高而出现气孔。如果过短，则高速过早，可能引起卷气。因此，应优化慢速行程，确保铝液以平稳状态进入高速阶段。
- 减少皮下气孔倾向: 气孔位于皮下加工层，毛坯探伤时因表面致密层掩盖而未显影。机加工去除表层后暴露。说明皮下存在气孔，需改善表层致密度，如提高铸造压力，或减少皮下气孔倾向。
