四、检索文本：
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 提高铸件致密度: 热处理加热时，缩孔周围组织软化，内部气体膨胀，可能导致缩孔扩大。若缩孔与表面连通，可能鼓泡。根本原因是原始缩孔严重。需提高铸件致密度，或调整热处理工艺（如降低温度、缩短时间）。
- 气泡核心: 大尺寸夹杂物易成为气泡核心，形成大气孔；细小夹杂物可能形成多个小气孔。夹杂物越多，气孔倾向越大。需通过过滤去除大夹杂，精炼去除细小夹杂。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 缩孔: 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 形成气孔: 高湿度下，脱模剂可能吸湿，喷涂时水分增多，遇到铝液产生大量气体，形成气孔。应使用高浓度脱模剂，减少喷涂量，并确保压缩空气干燥。同时加强排气，避免气体滞留。
- 夹杂: 静置时间过长，铝液可能重新吸氢，尤其是环境湿度高时，气孔增加。同时氧化物可能下沉或上浮，若浇注时卷入，成为夹杂。精炼后应在合理时间内使用，否则需重新除气。保温炉需加盖覆盖剂。
- 涡流卷气: 连接处流动速度突变，易产生涡流卷气。同时厚壁处气体可能向薄壁处逸出。需优化过渡圆角，使流动平稳。调整高速速度，避免湍流。
