四、检索文本：
- 除气: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
- 优化浇口: 镶件预热可减少温差，避免局部热节。同时，在镶件周围增加挤压销，或优化浇口，使压力能传递到。也可改变镶件设计，使其更易补缩。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 缩松: 铸造压力增大，缩松减少，直至消失。但缩松还与合金特性有关。对于宽凝固范围合金，高压也难以完全消除缩松，需配合模温控制。
- 高速行程: 高速行程与浇口厚度无关，但浇口厚度影响补缩，间接影响高速起点的选择。厚浇口允许稍晚高速，因补缩通道持久。
- 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 优先调整高速行程和排气系统。高速起点决定了气体被推到哪个区域，通过调整可以将气体引入溢流槽。同时检查排气槽是否堵塞或面积不足。如果调整后气孔位置移动但未消除，可结合高速速度微调。
- 缩孔: 建压时间短且料饼厚时，压力能迅速有效传递，缩孔减少。若建压时间长，即使料饼厚，压力到达时浇口可能已凝固，缩孔仍存。现场应优先缩短建压时间，同时保证料饼厚度足够，两者需匹配。
- 铝温: 铝温影响铸态组织，进而影响热处理后的尺寸变化。高温铸件组织粗大，热处理后尺寸变化可能较大。需控制铝温，保证组织均匀。
