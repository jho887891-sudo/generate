- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 缩孔位置: 培训重点：气孔边缘光滑、圆形，缩孔边缘锯齿状、不规则。气孔颜色均匀，缩孔深浅不一。气孔分散，缩孔集中在热节。结合铸件结构判断，厚大区域多缩孔，薄壁区多气孔。多看图对比。
- 流动性变差: 硅含量过高，初晶硅粗大，流动性变差，补缩困难，缩孔增加。同时热裂倾向大。需控制硅含量在共晶点附近。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 缩孔: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 排气: 硅含量影响合金流动性。高硅铝合金流动性好，有利于排气，减少卷气孔；但硅含量过高易产生集中缩孔。低硅合金流动性差，易产生冷隔和分散气孔。需根据铸件结构选择合适的合金。
- 气孔核心: 钛是晶粒细化剂，适量钛可细化晶粒，减少气孔；但过量钛可能形成TiAl3夹杂，成为气孔核心。需控制钛含量在0.1-0.2%。
