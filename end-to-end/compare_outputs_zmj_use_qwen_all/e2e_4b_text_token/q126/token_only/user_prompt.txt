四、检索文本：
- 增加排气: 推杆处常有气体残留，若推杆配合间隙大，气体可能被吸入。或推杆冷却不足，局部过热。需检查推杆配合，加强冷却，并在推杆附近增加排气。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 提高铸件致密度: 热处理加热时，缩孔周围组织软化，内部气体膨胀，可能导致缩孔扩大。若缩孔与表面连通，可能鼓泡。根本原因是原始缩孔严重。需提高铸件致密度，或调整热处理工艺（如降低温度、缩短时间）。
- 线状气孔可能是沿晶界或流线分布的微小气孔，在焊接时聚集形成。说明铸件该区域有微缩松或氧化夹杂。需提高铸件致密度，减少夹杂，并优化焊接工艺，如预热、选用合适焊材。
- 补缩: 铬含量低，影响不大；高铬可能形成金属间化合物，影响流动性，间接影响补缩。但铬在铝合金中少见。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 排气: 硅含量影响合金流动性。高硅铝合金流动性好，有利于排气，减少卷气孔；但硅含量过高易产生集中缩孔。低硅合金流动性差，易产生冷隔和分散气孔。需根据铸件结构选择合适的合金。
- 补缩不足: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
