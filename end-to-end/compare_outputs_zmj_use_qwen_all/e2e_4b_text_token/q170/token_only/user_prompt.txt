四、检索文本：
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 减少: 慢速速度调慢减少了压射室内的卷气，使进入型腔的初始气体总量减少。焊接区域作为铸件的一部分，其含气量也随之降低，因此焊接时气孔减少。这说明该焊接区域的气孔主要来自慢速卷气。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 大气孔: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
- 补缩: 铬含量低，影响不大；高铬可能形成金属间化合物，影响流动性，间接影响补缩。但铬在铝合金中少见。
- 气体: 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
