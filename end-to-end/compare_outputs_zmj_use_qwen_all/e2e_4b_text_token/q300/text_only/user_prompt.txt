四、检索文本：
- 气孔: 这是典型的气缩孔复合缺陷。厚大区域凝固时间长，一方面铝液中的氢气在凝固过程中析出，形成细小氢气孔；另一方面，如果补缩不足，产生缩孔。同时，如果慢速卷气产生的气泡在浮力作用下也可能上浮聚集在厚大区域。因此，缩孔周围常伴有细小气孔。解决需同时改善铝液质量和补缩条件。
- 缩短建压时间: 壁厚增加，体积收缩量增大，凝固时间延长，若无相应补缩措施，缩孔倾向显著增加。缩孔体积与壁厚平方成正比。需相应增大铸造压力、缩短建压时间、加强局部冷却，并考虑增加料饼厚度。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 氧化膜增厚: 慢速过慢，氧化膜增厚，可能卷入形成夹杂；过快，卷气带入氧化。合适的慢速可减少夹杂。同时，铝液需除渣。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高速填充结束瞬间: 增压起始点通常设在高速填充结束瞬间。若起始点过早，可能未充满即增压，导致欠铸；过晚，浇口凝固，增压无效。需通过行程开关或压射曲线准确设定起始点。
- 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 慢速行程: 慢速行程影响铝液在压射室内的停留时间和卷气量。如果慢速行程过长，铝液降温多，卷气机会增加，焊接区域可能因含气量高而出现气孔。如果过短，则高速过早，可能引起卷气。因此，应优化慢速行程，确保铝液以平稳状态进入高速阶段。
- 气孔边缘光滑、形状规则，颜色均匀；缩孔边缘不规则、呈树枝状或锯齿状，颜色深浅不一。气孔多分散，缩孔多集中在热节区。结合位置可准确判断。
