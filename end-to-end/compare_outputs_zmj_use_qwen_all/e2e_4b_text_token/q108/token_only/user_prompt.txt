四、检索文本：
- 缩短建压时间: 壁厚增加，体积收缩量增大，凝固时间延长，若无相应补缩措施，缩孔倾向显著增加。缩孔体积与壁厚平方成正比。需相应增大铸造压力、缩短建压时间、加强局部冷却，并考虑增加料饼厚度。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 增压器状态: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 缩孔消失: 压力越大，缩孔体积越小。但存在极限，当压力足以消除所有收缩时，缩孔消失。若仍有缩孔，说明压力不足或补缩通道不畅。可通过试验找出临界压力。
- 厚大区域: 循环周期变长意味着模具冷却时间增加，模温下降。如果模温过低，金属液进入型腔后降温过快，补缩通道提前凝固，可能导致原本补缩良好的区域出现缩孔。特别是厚大区域，对模温敏感，模温过低会使缩孔集中出现。此时应适当缩短周期或加强保温，维持模温在合理范围。
- 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 缩孔: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 高速填充结束瞬间: 增压起始点通常设在高速填充结束瞬间。若起始点过早，可能未充满即增压，导致欠铸；过晚，浇口凝固，增压无效。需通过行程开关或压射曲线准确设定起始点。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 料饼厚度: 经验公式：高速起点 = 料饼厚度 + 浇注系统体积对应的行程。浇注系统体积包括直浇道、横浇道、内浇口。计算后通过试模修正。
