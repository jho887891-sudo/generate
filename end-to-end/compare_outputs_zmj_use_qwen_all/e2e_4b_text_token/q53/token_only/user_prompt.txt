四、检索文本：
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 补缩: 高速行程与浇口厚度无关，但浇口厚度影响补缩，间接影响高速起点的选择。厚浇口允许稍晚高速，因补缩通道持久。
- 气孔: 这是典型的气缩孔复合缺陷。厚大区域凝固时间长，一方面铝液中的氢气在凝固过程中析出，形成细小氢气孔；另一方面，如果补缩不足，产生缩孔。同时，如果慢速卷气产生的气泡在浮力作用下也可能上浮聚集在厚大区域。因此，缩孔周围常伴有细小气孔。解决需同时改善铝液质量和补缩条件。
- 提高铸件致密度: 热处理加热时，缩孔周围组织软化，内部气体膨胀，可能导致缩孔扩大。若缩孔与表面连通，可能鼓泡。根本原因是原始缩孔严重。需提高铸件致密度，或调整热处理工艺（如降低温度、缩短时间）。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 铸造压力: 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 厚大区域: 循环周期变长意味着模具冷却时间增加，模温下降。如果模温过低，金属液进入型腔后降温过快，补缩通道提前凝固，可能导致原本补缩良好的区域出现缩孔。特别是厚大区域，对模温敏感，模温过低会使缩孔集中出现。此时应适当缩短周期或加强保温，维持模温在合理范围。
- 慢速行程: 慢速行程影响铝液在压射室内的停留时间和卷气量。如果慢速行程过长，铝液降温多，卷气机会增加，焊接区域可能因含气量高而出现气孔。如果过短，则高速过早，可能引起卷气。因此，应优化慢速行程，确保铝液以平稳状态进入高速阶段。
- 分散气孔: 硅含量影响合金流动性。高硅铝合金流动性好，有利于排气，减少卷气孔；但硅含量过高易产生集中缩孔。低硅合金流动性差，易产生冷隔和分散气孔。需根据铸件结构选择合适的合金。
- 气孔边缘光滑、形状规则，颜色均匀；缩孔边缘不规则、呈树枝状或锯齿状，颜色深浅不一。气孔多分散，缩孔多集中在热节区。结合位置可准确判断。
