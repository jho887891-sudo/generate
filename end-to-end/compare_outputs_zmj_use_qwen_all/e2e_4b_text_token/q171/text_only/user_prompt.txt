- 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 慢速速度调慢: 慢速速度调慢减少了压射室内的卷气，使进入型腔的初始气体总量减少。焊接区域作为铸件的一部分，其含气量也随之降低，因此焊接时气孔减少。这说明该焊接区域的气孔主要来自慢速卷气。
- 铸造压力: 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 除气: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 最后填充区: 模拟软件可设置不同高速起点，观察流动前沿。找到使最后填充区位于溢流槽且无卷气的起点。同时检查浇口处是否先充满。
- 补缩不足: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 高速行程: 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
