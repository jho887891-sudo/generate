四、检索文本：
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 压力: 压力对气孔的压缩效果取决于气孔大小和位置。孤立大气孔可被压缩，但微小气孔可能不受影响。压力只能压缩，不能消除，需结合除气。
- 加强冷却: 分散性缩孔通常由整体补缩不足引起，如铸造压力过低、料饼太薄、铝液温度过高导致整体凝固慢，使铸件各处都有微小缩松。集中性缩孔则由局部热节补缩失效引起，如厚大区域浇口凝固过早、局部压力传递受阻。前者需整体调整参数，后者需针对局部优化（如加强冷却、增加挤压销）。
- 铸造压力: 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 夹杂: 静置时间过长，铝液可能重新吸氢，尤其是环境湿度高时，气孔增加。同时氧化物可能下沉或上浮，若浇注时卷入，成为夹杂。精炼后应在合理时间内使用，否则需重新除气。保温炉需加盖覆盖剂。
- 气缩孔: 熔炼温度过高，铝液吸氢加剧，含气量增加，凝固时析出氢气孔。同时氧化严重，产生氧化夹杂，可能形成气缩孔。
- 填充模式: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 涡流卷气: 连接处流动速度突变，易产生涡流卷气。同时厚壁处气体可能向薄壁处逸出。需优化过渡圆角，使流动平稳。调整高速速度，避免湍流。
