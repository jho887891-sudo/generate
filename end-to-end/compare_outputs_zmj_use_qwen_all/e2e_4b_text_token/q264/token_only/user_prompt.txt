四、检索文本：
- 缩短建压时间: 壁厚增加，体积收缩量增大，凝固时间延长，若无相应补缩措施，缩孔倾向显著增加。缩孔体积与壁厚平方成正比。需相应增大铸造压力、缩短建压时间、加强局部冷却，并考虑增加料饼厚度。
- 压力: 压力对气孔的压缩效果取决于气孔大小和位置。孤立大气孔可被压缩，但微小气孔可能不受影响。压力只能压缩，不能消除，需结合除气。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 增压压力能在内浇口凝固前到达型腔: 建压时间缩短意味着增压压力能在内浇口凝固前到达型腔，从而对厚大区域进行有效补缩。集中性缩孔正是因为补缩失效而产生的，所以缩短建压时间能直接改善。现场应检查液压系统响应，确保建压时间尽可能短，并监控压射曲线。
- 缩孔位置: 培训重点：气孔边缘光滑、圆形，缩孔边缘锯齿状、不规则。气孔颜色均匀，缩孔深浅不一。气孔分散，缩孔集中在热节。结合铸件结构判断，厚大区域多缩孔，薄壁区多气孔。多看图对比。
- 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 高速填充结束瞬间: 增压起始点通常设在高速填充结束瞬间。若起始点过早，可能未充满即增压，导致欠铸；过晚，浇口凝固，增压无效。需通过行程开关或压射曲线准确设定起始点。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 涡流卷气: 连接处流动速度突变，易产生涡流卷气。同时厚壁处气体可能向薄壁处逸出。需优化过渡圆角，使流动平稳。调整高速速度，避免湍流。
- 优化浇口: 镶件预热可减少温差，避免局部热节。同时，在镶件周围增加挤压销，或优化浇口，使压力能传递到。也可改变镶件设计，使其更易补缩。
