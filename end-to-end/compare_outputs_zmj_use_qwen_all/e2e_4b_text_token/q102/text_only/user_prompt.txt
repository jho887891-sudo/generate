四、检索文本：
- 高速行程: 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
- 增加排气: 推杆处常有气体残留，若推杆配合间隙大，气体可能被吸入。或推杆冷却不足，局部过热。需检查推杆配合，加强冷却，并在推杆附近增加排气。
- 压力: 压力对气孔的压缩效果取决于气孔大小和位置。孤立大气孔可被压缩，但微小气孔可能不受影响。压力只能压缩，不能消除，需结合除气。
- 局部挤压销: 在油孔处增加局部挤压销，或增加冷却水道。改变油孔位置，避开热节。若油孔是通孔，可考虑在另一侧增加补缩。
- 热裂倾向: 锡含量低，影响不大；锡高可能形成低熔点相，增加热裂倾向，但对缩孔直接影响小。锡在铝合金中少见。
- 形成气孔: 高湿度下，脱模剂可能吸湿，喷涂时水分增多，遇到铝液产生大量气体，形成气孔。应使用高浓度脱模剂，减少喷涂量，并确保压缩空气干燥。同时加强排气，避免气体滞留。
- 圆形: 含氢量升高会导致气孔数量显著增加，直径略有增大，分布从稀疏变为密集，厚大区域出现簇状气孔。气孔形态仍保持圆形，但边界可能因相互连接而模糊。
- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 优化浇口: 镶件预热可减少温差，避免局部热节。同时，在镶件周围增加挤压销，或优化浇口，使压力能传递到。也可改变镶件设计，使其更易补缩。
