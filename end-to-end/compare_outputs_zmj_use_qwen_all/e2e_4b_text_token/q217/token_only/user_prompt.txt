四、检索文本：
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 大气孔: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
- 提高铸件致密度: 线状气孔可能是沿晶界或流线分布的微小气孔，在焊接时聚集形成。说明铸件该区域有微缩松或氧化夹杂。需提高铸件致密度，减少夹杂，并优化焊接工艺，如预热、选用合适焊材。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 补缩不足: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 铝液降温多: 慢速行程影响铝液在压射室内的停留时间和卷气量。如果慢速行程过长，铝液降温多，卷气机会增加，焊接区域可能因含气量高而出现气孔。如果过短，则高速过早，可能引起卷气。因此，应优化慢速行程，确保铝液以平稳状态进入高速阶段。
