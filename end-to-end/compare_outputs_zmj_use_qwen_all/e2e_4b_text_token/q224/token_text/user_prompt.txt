四、检索文本：
- 流动性: 硅含量升高，流动性改善，凝固范围变窄，补缩性能提高，缩孔倾向减小。共晶合金体积收缩率也较低。因此，提高硅含量有助于减少缩孔，但需注意过共晶硅粗大反而降低性能，控制在共晶点附近最佳。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 减少气孔: 钛是晶粒细化剂，适量钛可细化晶粒，减少气孔；但过量钛可能形成TiAl3夹杂，成为气孔核心。需控制钛含量在0.1-0.2%。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 缩孔: 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 料饼厚度: 料饼厚度减小导致补缩压力传递能力下降。厚大区域需要长时间、大压力的补缩，如果料饼太薄，压力在传递过程中因料饼凝固而中断，该区域无法得到持续补缩，缩孔就会集中出现。此外，料饼薄还会使建压时间变长，进一步削弱补缩效果。应增加料饼厚度至合理范围。
- 慢速卷气: 慢速速度调慢减少了压射室内的卷气，使进入型腔的初始气体总量减少。焊接区域作为铸件的一部分，其含气量也随之降低，因此焊接时气孔减少。这说明该焊接区域的气孔主要来自慢速卷气。
- 卷气机会增加: 慢速行程影响铝液在压射室内的停留时间和卷气量。如果慢速行程过长，铝液降温多，卷气机会增加，焊接区域可能因含气量高而出现气孔。如果过短，则高速过早，可能引起卷气。因此，应优化慢速行程，确保铝液以平稳状态进入高速阶段。
