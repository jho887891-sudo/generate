- 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 优化: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 光亮环: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 热裂倾向: 锡含量低，影响不大；锡高可能形成低熔点相，增加热裂倾向，但对缩孔直接影响小。锡在铝合金中少见。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 气缩孔: 熔炼温度过高，铝液吸氢加剧，含气量增加，凝固时析出氢气孔。同时氧化严重，产生氧化夹杂，可能形成气缩孔。
- 涡流卷气: 连接处流动速度突变，易产生涡流卷气。同时厚壁处气体可能向薄壁处逸出。需优化过渡圆角，使流动平稳。调整高速速度，避免湍流。
- 增加排气: 推杆处常有气体残留，若推杆配合间隙大，气体可能被吸入。或推杆冷却不足，局部过热。需检查推杆配合，加强冷却，并在推杆附近增加排气。
