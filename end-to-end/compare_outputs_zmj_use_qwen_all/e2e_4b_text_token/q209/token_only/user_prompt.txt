四、检索文本：
- 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 检查镶件: 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 优化: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 气孔增多: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 锌含量升高，合金熔点降低，流动性改善，但吸氢倾向增加，气孔可能增多。尤其是在高湿度环境下。需加强除气，并控制锌含量在合金标准内。对于高锌合金，需特别注意熔炼工艺。
- 铝温: 铝温影响铸态组织，进而影响热处理后的尺寸变化。高温铸件组织粗大，热处理后尺寸变化可能较大。需控制铝温，保证组织均匀。
