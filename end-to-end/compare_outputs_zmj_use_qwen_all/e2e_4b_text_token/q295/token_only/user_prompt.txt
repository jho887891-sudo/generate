四、检索文本：
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 牙孔区域气孔: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 内浇口速度: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 补缩: 铬含量低，影响不大；高铬可能形成金属间化合物，影响流动性，间接影响补缩。但铬在铝合金中少见。
- 原速度: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 金属液从慢速到高速的过渡平稳性: 比值决定金属液从慢速到高速的过渡平稳性。比值不当易在切换点产生卷气。一般推荐慢速临界速度以下，高速速度根据浇口面积计算，确保切换时金属液已到达内浇口且无波动。通过模拟或经验优化比值可减少气孔。
- 填充时间延长: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
