四、检索文本：
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 细化晶粒: 钪是稀有元素，可细化晶粒，提高性能，但对气孔无直接作用。成本高，很少用。
- 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 流动性: 铁含量高会形成脆性相，降低流动性，使补缩困难，缩孔倾向增加。同时，铁相可能堵塞补缩通道。但适量铁可减少粘模。需控制在合理范围。
- 优化: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 气泡核心: 大尺寸夹杂物易成为气泡核心，形成大气孔；细小夹杂物可能形成多个小气孔。夹杂物越多，气孔倾向越大。需通过过滤去除大夹杂，精炼去除细小夹杂。
- 气缩孔: 熔炼温度过高，铝液吸氢加剧，含气量增加，凝固时析出氢气孔。同时氧化严重，产生氧化夹杂，可能形成气缩孔。
- 除气: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 填充时间延长: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
