2. 用同料号、同模次或相近工况样本对照，观察参数变化时缺陷分布是否同步变化。
3. 以后遇到相似问题时，应优先调出同料号样本，把样本编号、参数前缀和视觉/区域前缀放在一起比较，持续观察参数变化和缺陷变化是否同步。
