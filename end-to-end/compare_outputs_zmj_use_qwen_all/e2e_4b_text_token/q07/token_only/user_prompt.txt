四、检索文本：
- 投影面积: 高速行程主要影响填充顺序，与投影面积无直接关系。但投影面积大的铸件通常需要更长的填充时间，因此高速行程可能较长。需根据浇注系统设计来确定高速起点。
- 填充模式: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 减少气孔: 钛是晶粒细化剂，适量钛可细化晶粒，减少气孔；但过量钛可能形成TiAl3夹杂，成为气孔核心。需控制钛含量在0.1-0.2%。
- 加强冷却: 分散性缩孔通常由整体补缩不足引起，如铸造压力过低、料饼太薄、铝液温度过高导致整体凝固慢，使铸件各处都有微小缩松。集中性缩孔则由局部热节补缩失效引起，如厚大区域浇口凝固过早、局部压力传递受阻。前者需整体调整参数，后者需针对局部优化（如加强冷却、增加挤压销）。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 厚大区域: 循环周期变长意味着模具冷却时间增加，模温下降。如果模温过低，金属液进入型腔后降温过快，补缩通道提前凝固，可能导致原本补缩良好的区域出现缩孔。特别是厚大区域，对模温敏感，模温过低会使缩孔集中出现。此时应适当缩短周期或加强保温，维持模温在合理范围。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
