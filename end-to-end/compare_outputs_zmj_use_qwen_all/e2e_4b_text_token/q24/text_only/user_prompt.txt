四、检索文本：
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 缩孔: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 冷隔: 铝液温度高时，缩孔通常较大且不规则，因凝固时间长、收缩量大；温度低时，缩孔较小但可能伴随冷隔。高温缩孔多集中在最后凝固区，低温缩孔可能更分散。需根据缺陷调整温度。
- 铝液温度: 铝液温度高时，缩孔通常较大且不规则，因凝固时间长、收缩量大；温度低时，缩孔较小但可能伴随冷隔。高温缩孔多集中在最后凝固区，低温缩孔可能更分散。需根据缺陷调整温度。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 投影面积: 高速行程主要影响填充顺序，与投影面积无直接关系。但投影面积大的铸件通常需要更长的填充时间，因此高速行程可能较长。需根据浇注系统设计来确定高速起点。
- 夹杂: 静置时间过长，铝液可能重新吸氢，尤其是环境湿度高时，气孔增加。同时氧化物可能下沉或上浮，若浇注时卷入，成为夹杂。精炼后应在合理时间内使用，否则需重新除气。保温炉需加盖覆盖剂。
- 缩孔集中: 若气孔多且分散，缩孔集中，则气孔为主，需先除气；若缩孔大且位于热节，气孔少，则缩孔为主，需加强补缩。通过分析位置、形态可判断，并针对性处理。
- 增大铸造压力: 铝液温度高时，凝固时间长，需要更大的铸造压力来补偿收缩；温度低时，凝固快，压力需求相对小，但充填困难。因此，高温时宜适当增大铸造压力，低温时需注意充填速度和压力传递时间。
- 加强除气: 锌含量升高，合金熔点降低，流动性改善，但吸氢倾向增加，气孔可能增多。尤其是在高湿度环境下。需加强除气，并控制锌含量在合金标准内。对于高锌合金，需特别注意熔炼工艺。
