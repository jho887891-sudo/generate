- 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
- 高速行程: 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
- 减少皮下气孔倾向: 气孔位于皮下加工层，毛坯探伤时因表面致密层掩盖而未显影。机加工去除表层后暴露。说明皮下存在气孔，需改善表层致密度，如提高铸造压力，或减少皮下气孔倾向。
- 加强除气: 鼓泡可能由皮下微气孔群引起，常规探伤分辨率不足未检出。热处理时气体膨胀，将表层顶起。需提高探伤精度，或通过金相检查。加强除气可预防。
- 气体: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 优化补缩: 根本原因是厚大区域是热节，凝固速度最慢。在凝固过程中，体积收缩需要补缩，如果补缩压力不足或补缩通道不畅，就会形成缩孔。同时，最后凝固的区域也是气体析出聚集的地方。因此，厚大区域容易同时出现缩孔和气孔，形成复合缺陷。解决思路是加强冷却、优化补缩和排气。
- 除气: 光亮环可能是缩孔周围致密层在X光下的投影，因密度差异形成。常见于较大缩孔。说明缩孔周围组织较致密，但缩孔本身需处理。应分析缩孔成因，若是补缩不足，则增大压力；若是气体，则除气。
- 高压: 有一定改善，高压可将部分气孔压缩，但无法消除根源。对于大的卷气孔，压力可能使其变形但依然存在。因此，主要措施仍是减少气体来源。
- 牙孔区域过热: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 锌含量升高，合金熔点降低，流动性改善，但吸氢倾向增加，气孔可能增多。尤其是在高湿度环境下。需加强除气，并控制锌含量在合金标准内。对于高锌合金，需特别注意熔炼工艺。
