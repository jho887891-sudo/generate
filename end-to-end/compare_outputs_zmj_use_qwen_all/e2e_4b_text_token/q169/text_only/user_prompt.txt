四、检索文本：
- 填充模式: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 缩孔形状: 压力大，缩孔被压缩，形态趋于扁平；压力小，缩孔保持树枝状。通过压力可改变缩孔形状，但消除需足够压力。
- 流动性: 硅含量升高，流动性改善，凝固范围变窄，补缩性能提高，缩孔倾向减小。共晶合金体积收缩率也较低。因此，提高硅含量有助于减少缩孔，但需注意过共晶硅粗大反而降低性能，控制在共晶点附近最佳。
- 铸造压力: 铸造压力指最终作用在金属液上的压力，通常由增压系统产生。增压压力是液压系统提供的压力，经增压器放大后得到铸造压力。两者关系：铸造压力=增压比×增压压力。调整时需注意增压器状态。
- 可以设定不同的铸造压力，在其他参数不变的情况下生产样品，然后对焊接区域进行探伤和焊接试验。观察随着压力增大，焊接区域缺陷是否减少。如果减少，说明压力有效；如果无明显变化，则需检查补缩通道。
- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 缩孔: 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 减少缩孔: 硅含量升高，流动性改善，凝固范围变窄，补缩性能提高，缩孔倾向减小。共晶合金体积收缩率也较低。因此，提高硅含量有助于减少缩孔，但需注意过共晶硅粗大反而降低性能，控制在共晶点附近最佳。
- 加强除气: 锌含量高，合金熔点低，流动性好，但易吸氢，气孔倾向大。需加强除气。锌合金压铸时需特别注意。
- 除气: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
