四、检索文本：
- 优化补缩: 根本原因是厚大区域是热节，凝固速度最慢。在凝固过程中，体积收缩需要补缩，如果补缩压力不足或补缩通道不畅，就会形成缩孔。同时，最后凝固的区域也是气体析出聚集的地方。因此，厚大区域容易同时出现缩孔和气孔，形成复合缺陷。解决思路是加强冷却、优化补缩和排气。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 压力: 压力对气孔的压缩效果取决于气孔大小和位置。孤立大气孔可被压缩，但微小气孔可能不受影响。压力只能压缩，不能消除，需结合除气。
- 除气: 大小不一的气孔可能由多种来源混合：大气孔可能由卷气团形成，小气孔可能由氢气析出。需综合分析，检查慢速卷气和铝液含气量。优化慢速和除气可改善。
- 顶杆配合间隙: 顶杆卡滞导致顶出阻力大，可能顶伤铸件表面，形成凹坑或裂纹，探伤时可能误判为缩孔。同时卡滞使顶杆复位不到位，下次合模时可能压坏模具或产生飞边，气体易进入。需调整顶杆配合间隙，保证顶出顺畅。
- 投影面积: 高速行程主要影响填充顺序，与投影面积无直接关系。但投影面积大的铸件通常需要更长的填充时间，因此高速行程可能较长。需根据浇注系统设计来确定高速起点。
- 填充模式: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 缩孔集中: 若气孔多且分散，缩孔集中，则气孔为主，需先除气；若缩孔大且位于热节，气孔少，则缩孔为主，需加强补缩。通过分析位置、形态可判断，并针对性处理。
- 增大压力: 增大压力可将树枝状缩孔压扁，甚至消除。但需配合建压时间。压力足够时，缩孔变为微小疏松，可接受。
- 优化浇口: 镶件预热可减少温差，避免局部热节。同时，在镶件周围增加挤压销，或优化浇口，使压力能传递到。也可改变镶件设计，使其更易补缩。
