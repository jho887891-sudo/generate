- 压射压力: 慢速阶段所需压力很小，主要克服摩擦阻力。压射压力主要针对高速和增压阶段。两者无直接关联，但慢速速度波动可能反映压射系统不稳定。
- 建压时间: 油温影响液压油粘度，从而影响建压时间。油温高，粘度低，建压快；油温低，建压慢。
- 后移: 现场可逐步后移射料结束位置，连续生产几模后探伤对比牙孔区域缩孔变化。找到缩孔最少的位置，即为最佳结束位置。注意不要过度后移导致材料浪费或飞边。
- 优化: 内浇口速度与截面积成反比，截面积加大，速度降低。若原速度超过临界值，降低后可减少喷射卷气，气孔减少。但若原速度已偏低，进一步降低可能导致填充时间延长，增加冷隔风险。需根据原速度优化。
- 除气: 湿度高导致原始气孔多，热处理后气孔扩大，力学性能下降。尤其是延伸率降低明显。需控制湿度，加强除气。
- 气孔在铸件内分布不均匀: 说明气孔在铸件内分布不均匀。可能焊接区域处于不同填充位置，气体聚集区气孔多。需分析焊接区域在型腔中的位置，调整高速起点使气体避开该区域，或增加溢流槽收集气体。
- 排气: 硅含量影响合金流动性。高硅铝合金流动性好，有利于排气，减少卷气孔；但硅含量过高易产生集中缩孔。低硅合金流动性差，易产生冷隔和分散气孔。需根据铸件结构选择合适的合金。
- 缩孔: 增加建压时间会使压力更晚到达，补缩更无效，缩孔更严重。因此不能通过增加建压时间改善缩孔，反而应缩短建压时间。正确方向是缩短建压时间，确保压力在内浇口凝固前到达。
- 冷却: 液压油温升高，粘度降低，响应加快，建压时间缩短；油温低，粘度大，建压时间延长。因此，保持油温稳定有助于建压时间稳定。冬季需预热，夏季需冷却。
- 金属液从慢速到高速的过渡平稳性: 比值决定金属液从慢速到高速的过渡平稳性。比值不当易在切换点产生卷气。一般推荐慢速临界速度以下，高速速度根据浇口面积计算，确保切换时金属液已到达内浇口且无波动。通过模拟或经验优化比值可减少气孔。
