【溯源分析】
1. 区域证据来自视觉/区域前缀信息，应把区域分布作为先验分布，而不是把某个缺陷图像或文字描述作为唯一依据。区域分布能反映缺陷在样本中出现的频率和空间范围，比单张图片更能说明问题。
2. 从参数链看，高速行程影响高速充型稳定性，建压时间决定压力建立速度，压射压力和铸造压力决定压力传递和补压状态。三者共同决定高速后半段的充型稳定和补压有效。
3. 不能只看参数值或缺陷分布，而应看参数链是否与缺陷位置一致。若某一张样本的缺陷集中出现在高速行程或建压时间相近位置，说明该参数链需要优先复核。

【建议方向】
1. 先按补压、内浇口、高速行程和建压时间的工艺链路复核，再看压力传递是否稳定。
2. 用同料号、同视角样本对照高速行程和建压时间变化，判断缺陷是否随参数调整而收敛。
3. 从同料号样本中找相似缺陷分布，确认是局部性缺陷放大，还是整体压力链不稳定。
