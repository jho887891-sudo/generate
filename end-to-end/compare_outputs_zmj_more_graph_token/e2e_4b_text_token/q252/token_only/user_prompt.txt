四、检索文本：
- 高速起点: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 高速行程: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 高速行程决定了高速起点的位置，从而影响金属液在型腔内的填充顺序。如果高速起点设置不当，焊接区域可能成为气体聚集区或最后填充区，导致气孔集中。通过调整高速行程，可以将气体引导至溢流槽，避免焊接区域卷入气体。同时，高速行程也影响焊接区域的充填时间，间接影响温度场。
- 最后填充区: 通过模拟可预测最后填充区，即热节位置。调整高速起点，可移动热节。结合冷却系统，使热节处得到有效补缩。
- 优化高速起点: 增大铸造压力，缩短建压时间，提高料饼厚度，加强局部冷却。同时优化高速起点，使厚大区域避开最后填充，或使其在增压前充满。
- 高速行程影响填充方向，从而影响流线分布。合理的流线应顺着铸件形状，避免涡流。若高速起点不当，流线紊乱，可能产生气孔和裂纹。

- 铸件形状: 高速行程影响填充方向，从而影响流线分布。合理的流线应顺着铸件形状，避免涡流。若高速起点不当，流线紊乱，可能产生气孔和裂纹。
- 高速速度: 两者独立，但共同决定填充过程。慢速速度影响初始卷气和温降，高速速度影响填充时间和卷气。优化时需分别设定，确保慢速平稳、高速快速且不喷射。
- 气孔: 高湿度下，脱模剂易吸水，润滑效果下降，可能导致粘模。同时，水汽产生气孔，使铸件表面粗糙，增加脱模阻力。需调整脱模剂配方或喷涂量。
