- 正常。高速行程决定了金属液开始高速填充的位置，直接影响气体的聚集区域。当高速起点改变时，气体被推动的路径和最终位置也会改变，因此集中性气孔的位置会相应移动。这正是通过调整高速行程将气体引入溢流槽的理论依据。现场可以逐步调整高速起点，观察气孔位置变化，找到最佳设置。
- 卷气: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 高速行程: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 内浇口厚度: 内浇口厚度通常为铸件壁厚的50%-80%，以保证补缩通道在铸件凝固前不封闭。壁厚大时，浇口应相应加厚。比例不当会导致缩孔，需通过模拟验证。
- 气体分布: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。
- 慢速速度过高，易产生湍流卷气，导致分散气孔。需根据压射室直径计算临界速度，确保慢速在临界值以下，使金属液平稳上升，避免卷气。
- 射料结束位置: 现场可逐步后移射料结束位置，连续生产几模后探伤对比牙孔区域缩孔变化。找到缩孔最少的位置，即为最佳结束位置。注意不要过度后移导致材料浪费或飞边。
- 慢速行程短意味着高速起点早，金属液过早进入高速阶段。这可能导致铝液在压射室内停留时间不足，温度较高，但同时也可能因高速过早引起卷气。如果卷气产生的气体最终聚集在牙孔区域，就会形成气孔；而缩孔增多则可能是因为高速过早导致填充模式变化，使牙孔区域补缩不足。实际上，慢速行程应与慢速速度匹配，保证金属液平稳推进到内浇口。
