四、检索文本：
- 缩孔: 在厚大区域设置挤压销，在凝固后期启动，施加局部压力补缩，消除缩孔。挤压销直径、位置和启动时间需优化，通常通过模拟确定。可有效解决孤立缩孔。
- 加强冷却: 气孔导致材料缺失，加工时刀具可能偏向缺陷，或气孔处强度低，加工后变形。需先解决气孔问题，同时检查加工余量是否过大。优化参数减少该区域气孔，如加强冷却、调整高速。
- 补缩不足: 复合缺陷需分析主因：若缩孔为主，气孔为辅，则补缩不足是主因；反之，气体是主因。根据参数调整方向，改进工艺。
- 厚大区域: 这是典型的气缩孔复合缺陷。厚大区域凝固时间长，一方面铝液中的氢气在凝固过程中析出，形成细小氢气孔；另一方面，如果补缩不足，产生缩孔。同时，如果慢速卷气产生的气泡在浮力作用下也可能上浮聚集在厚大区域。因此，缩孔周围常伴有细小气孔。解决需同时改善铝液质量和补缩条件。
- 气孔通常呈现为边缘光滑、形状规则多为圆形或椭圆形，内部密度均匀；缩孔则边缘呈不规则状或树枝状，颜色深浅不一，代表内部密度不均。
- 气孔: 气孔在焊接时成为应力集中点，热影响区收缩时沿气孔开裂。需减少该区域气孔，提高致密度。同时，焊接工艺上采用预热、缓冷，减小热应力。
- 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 射料结束位置决定了最终留在压室内的料饼厚度。位置太靠前意味着料饼过薄，无法为铸件提供足够的补缩压力。牙孔区域往往需要后期压力压实，一旦压力中断，该区域就会产生缩孔。此外，薄料饼还可能导致建压时间延长，进一步削弱补缩效果。现场应逐步后移结束位置，增加料饼厚度，观察缩孔改善情况。
- 铸件致密度: 有一定改善作用。较高的铸造压力可以将部分微小气孔压缩变小，甚至使气孔闭合，从而提高铸件致密度。但压力不能消除气孔产生的根源，因此改善程度有限。如果气孔很大或很多，单纯依靠压力无法根治，仍需从源头上减少气体卷入。
- 球形缩孔通常是气孔，边缘不规则可能是周围有缩松。说明气体与缩孔共存。需同时改善气体和补缩。
