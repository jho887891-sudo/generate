四、检索文本：
- 建压时间: 建压时间波动导致补缩效果不一致，铸件缩孔时有时无，质量不稳定。原因可能是液压油粘度变化、氮气压力波动、或阀响应异常。需检查液压系统，保持油温稳定，定期维护。
- 型腔气体: 真空压铸可抽出型腔气体，显著减少卷气孔，但对氢气孔无直接作用。需配合除气工艺。真空度越高，气孔越少，但需保证密封，否则效果有限。适合要求高的铸件。
- 真空压铸: 真空压铸可抽出型腔气体，显著减少卷气孔，但对氢气孔无直接作用。需配合除气工艺。真空度越高，气孔越少，但需保证密封，否则效果有限。适合要求高的铸件。
- 细小、分散的圆形或椭圆形: 慢速速度导致的气孔通常是由于卷气形成的，这些气孔多为细小、分散的圆形或椭圆形，分布无规律，整个铸件都可能出现。有时如果卷气严重，也可能形成较大的气孔，但总体特征是分散。
- 稀土元素: 稀土元素有净化、细化作用，可减少气孔。但过量可能形成稀土夹杂。适量添加可改善铸件质量，需试验确定。
- 产生气孔: 周期短，模温高，脱模剂易烧焦残留，下次喷涂时可能产生气体；周期长，模温低，脱模剂不易挥发，残留多。残留物遇铝液分解产生气孔。需优化喷涂量和周期，保持模温稳定。
- 铸造压力: 铸造压力产生的胀型力必须小于锁模力，否则模具会涨开，产生飞边、尺寸超差，甚至损坏模具。设定铸造压力时应计算投影面积上的总力，确保不超过锁模力的80%。
- 主因为气体: 复合缺陷需分析主因：若缩孔为主，气孔为辅，则补缩不足是主因；反之，气体是主因。根据参数调整方向，改进工艺。
- 补缩: 无直接关系。高速速度影响填充，料饼厚度影响补缩，两者独立。
- <水汽分解: 湿度高时空气中水汽多，慢速快会加剧卷气，将更多潮湿空气卷入铝液。水汽分解产生氢气，形成氢气孔，因此气孔明显增多。此时应降低慢速速度，并加强除气。
