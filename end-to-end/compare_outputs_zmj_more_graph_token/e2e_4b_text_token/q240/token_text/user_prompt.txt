四、检索文本：
- 模温: 周期缩短使模具吸热增多，模温上升，可能导致脱模剂失效、粘模、气孔增多（因气体膨胀）、缩孔增大（因凝固慢）。需同步调整冷却水流量或时间，维持模温稳定，必要时增加点冷。
- 填充顺序: 温度波动会导致金属液流动性、凝固时间和填充模式发生变化。原来稳定的填充顺序可能被打破，气体和缩孔位置发生漂移，从而在某些批次中集中出现在某一区域。因此，保持温度稳定是控制缺陷一致性的基础。
- 喷射卷气: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
- 高速速度过高: 高速速度过高会使合金液充型时剧烈紊流，卷入更多空气形成气孔；料温过高会增加合金液吸气量，同时加剧脱模剂分解挥发，进一步提升气孔产生风险。
- 气孔分布: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 厚大区域: 厚大区域对温度敏感。温度高时，缩孔倾向大，应加强冷却并增大铸造压力；温度低时，缩孔可能减少但气孔增加，需平衡。一般控制在工艺中限，并根据缺陷类型微调。
- <湿度高: 湿度高时，氢气孔的特征是细小、分散、圆形，有时呈蜂窝状分布，无明显聚集趋势。如果氢气严重，也可能在厚大区域聚集，形成较大气孔。探伤图上可见大量小黑点，密度较高，且往往整个铸件都有分布。此时应检查除气工艺和环境湿度。
- 循环周期短: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 高速速度: 两者独立，但共同决定填充过程。慢速速度影响初始卷气和温降，高速速度影响填充时间和卷气。优化时需分别设定，确保慢速平稳、高速快速且不喷射。
- 气孔: 高湿度下，脱模剂易吸水，润滑效果下降，可能导致粘模。同时，水汽产生气孔，使铸件表面粗糙，增加脱模阻力。需调整脱模剂配方或喷涂量。
