【溯源分析】
1. 区域证据是判断缺陷分布和参数影响范围的最小可观察单元。当前样本把建压时间作为线索，把相近样本的区域分布作为对照，比纯参数调整更准确地判断压力传递是否稳定。
2. 建压时间主要影响补压建立速度和压力传递一致性。时间过长时，凝固过程会持续把压力拉走；时间过短时，高速阶段可能还未结束，压力就可能提前进入补压阶段。当前样本的建压时间应与高速行程、铸造压力和压射曲线变化同步观察。
3. 区域分布可以快速判断压力集中区域，参数调整应以区域变化作为反馈，而不是只看缺陷数量或分布均匀性。

【建议方向】
1. 优先把建压时间作为同料号样本对照的变动起点，观察补压建立和凝固过程是否同步变化。
2. 谑料号样本时，应把建压时间与高速行程、铸造压力和压射曲线变化同时对比，确认参数链是否一致。
3. 验证方法应采用同料号、同视角、同工况样本前后对照，持续记录建压时间、高速行程和缺陷分布，形成可复现的诊断依据。
