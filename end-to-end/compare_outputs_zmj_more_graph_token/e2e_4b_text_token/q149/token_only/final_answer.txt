【结论】当前样本应优先把建压时间作为气孔风险的关键观察点，再判断铸造压力和高速充型是否形成协同风险。

【溯源分析】
1. 当前样本把“建压时间=114”作为视觉关注起点，说明当前判断应以高速行程、建压时间、铸造压力和补压状态共同决定的参数链为基础。慢速阶段的稳定和高速阶段的过渡决定了金属液进入型腔后的压力传递状态，若慢速阶段不稳或高速切换不及时，后续补压和铸造压力都可能无法有效传递。
2. 建压时间主要决定补压阶段的压力传递和补压有效性。若建压时间过长，铸造压力可能无法及时建立，补压阶段会不稳或不充分，同时高速阶段的卷气风险会同时放大。慢速行程和高速行程共同决定金属液进入型腔前的稳定状态，若慢速阶段不稳，高速阶段会更容易把气体带入型腔。
3. 电流、液压和压力表读数只能反映参数状态，不能替代高速、建压和补压过程观察。当前样本把建压时间作为风险关注点，是把慢速稳定、高速充型和补压状态放回工艺链中进行复核的起点。

【建议方向】
1. 先固定其他参数，单独观察建压时间变化对补压稳定性和气孔趋势的影响。
2. 后续验证应把同料号、同模次或相近工况样本作为对照，持续记录高速行程、建压时间和铸造压力的变化，判断参数调整是否真正改善了缺陷分布。
3. 若相近样本的缺陷分布或参数变化不一致，应优先把样本相近性、工艺一致性或热平衡相近样本放在一起复核，避免把偶然波动误判为参数风险。
