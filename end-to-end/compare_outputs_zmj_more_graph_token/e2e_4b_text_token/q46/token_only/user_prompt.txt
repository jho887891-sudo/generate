四、检索文本：
- 将气体压入铸件: 氮气压力过高，增压时冲击大，可能损坏模具或压铸机，同时可能将气体压入铸件，形成气孔。需按设备要求设定压力，避免过高。
- 与其他措施配合: 在补缩通道通畅的前提下，增大铸造压力可以消除厚大区域缩孔，直至达到设备极限或模具强度极限。如果压力已最大但缩孔仍存，说明通道不畅或需要改变凝固顺序。因此，铸造压力不是万能的，需与其他措施配合。
- 充氮压力过高: 充氮压力过高，增压时冲击力大，可能损坏模具或压铸机，同时可能将气体压入铸件形成气孔。建压时间虽短，但冲击可能导致飞边。需按设备说明书设定正确压力。
- 厚大区域: 厚大区域对温度敏感。温度高时，缩孔倾向大，应加强冷却并增大铸造压力；温度低时，缩孔可能减少但气孔增加，需平衡。一般控制在工艺中限，并根据缺陷类型微调。
- 铸造压力增大: 铸造压力增大并不能解决补缩通道提前凝固的问题。如果内浇口在增压压力到达之前已经凝固，再大的压力也无法传递到厚大区域。因此，必须同时检查浇口厚度是否足够、建压时间是否足够短，以及料饼厚度是否合理。只有在补缩通道通畅的前提下，增大铸造压力才能有效消除缩孔。
- <厚大区域: 厚大区域对温度敏感。温度高时，缩孔倾向大，应加强冷却并增大铸造压力；温度低时，缩孔可能减少但气孔增加，需平衡。一般控制在工艺中限，并根据缺陷类型微调。
- 组织更致密: 铸造压力直接影响铸件的致密度。较高的铸造压力可以使焊接区域的组织更致密，减少微观缩松，从而降低焊接时气体逸出的风险。但铸造压力不能解决卷气问题。如果焊接区域本身有气孔，压力只能压缩而不能消除。因此，需要结合其他参数共同优化。
- 形成气孔: 充氮压力过高，增压时冲击力大，可能损坏模具或压铸机，同时可能将气体压入铸件形成气孔。建压时间虽短，但冲击可能导致飞边。需按设备说明书设定正确压力。
