- 是气体聚集所致: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 气孔: 铬含量低，影响小；高铬可能形成化合物，影响流动性，间接影响气孔。但铬在铝合金中少见。
- 该区域质量: 说明气孔源于铸件本体。需返回压铸工序，优化该区域质量：调整高速起点，使焊接区避开气体聚集；加强冷却，提高致密度；控制铝液含气量。必要时改用低气孔率合金。
- 高速段: 微小波动一般不会直接导致气孔，但若波动频率高，可能引起液面轻微扰动，长期积累可能增加卷气风险。更重要的是检查波动原因，避免波动在高速段放大。稳定慢速有助于减少初始卷气。
- 气体: 油污遇高温汽化，产生气体，卷入金属液形成气孔，常位于铸件表面附近。同时油污燃烧产生积碳，影响脱模。需在合模前清洁分型面，使用耐高温润滑剂，避免过量喷涂。
- 硼: 硼可细化晶粒，改善补缩，间接减少缩孔。但过量可能形成硼化物。适量添加有益。
- 定期检查清理: 深度过浅，排气量不足，气体无法及时排出，形成气孔。需按规定深度加工，并定期检查清理，防止堵塞。
