四、检索文本：
- 合模不严: 飞边残留导致合模不严，形成微小缝隙，压射时气体从缝隙进入型腔，产生局部气孔。同时飞边可能脱落进入型腔成为夹杂。需及时清理分型面，确保合模平整。检查锁模力是否足够，避免飞边反复产生。
- 牙孔区域: 直接影响。牙孔区域通常需要足够的铸造压力来压实补缩。如果铸造压力不足，该区域在凝固时无法得到有效补缩，就会形成缩孔。但前提是压力必须能在内浇口凝固前传递进去，否则压力再大也无用。
- 足够的铸造压力: 直接影响。牙孔区域通常需要足够的铸造压力来压实补缩。如果铸造压力不足，该区域在凝固时无法得到有效补缩，就会形成缩孔。但前提是压力必须能在内浇口凝固前传递进去，否则压力再大也无用。
- 铸造压力: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
- 气孔: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 压射压力: 压射压力影响充填流速，进而影响气体聚集位置。适当调整压射压力可以微调气孔位置，但不能根治。优化时应以高速参数为主，压力为辅。例如，先调高速起点将气体引入溢流槽，再调压力确保平稳填充。
- 卷气: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 形成缩孔: 建压时间变长意味着从充填结束到建立最终铸造压力的时间间隔过长。在这段时间内，内浇口可能已经部分或完全凝固，导致增压压力无法有效传递到型腔内部的厚大区域。厚大区域由于最后凝固，如果没有足够的压力补缩，就会形成明显的缩孔。现场应检查液压系统响应、氮气压力，并尽可能缩短建压时间。
- 高压: 可能。大压力使局部大缩孔被压缩，但若补缩通道不畅，压力无法全面传递，周围区域可能出现微缩松。探伤图上表现为大缩孔消失，但出现细小疏松。此时需进一步改善通道或冷却。
- 最可能的原因: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
