四、检索文本：
- 慢速速度过快: 镁合金流动性好但易氧化，吸气倾向较铝合金低，但卷气同样会产生气孔。镁合金对模具温度更敏感，需严格控制模温。参数调整上，镁合金常用较低高速速度以避免喷射，且需注意脱模剂选择。
- 加强冷却: 气孔导致材料缺失，加工时刀具可能偏向缺陷，或气孔处强度低，加工后变形。需先解决气孔问题，同时检查加工余量是否过大。优化参数减少该区域气孔，如加强冷却、调整高速。
- 高速速度过高: 高速速度过高会使合金液充型时剧烈紊流，卷入更多空气形成气孔；料温过高会增加合金液吸气量，同时加剧脱模剂分解挥发，进一步提升气孔产生风险。
- 填充模式变化: 压力波动导致高速速度不稳定，填充模式变化，气体卷入量时大时小，气孔位置和大小随机。同时可能引起缩松。需检查液压系统、氮气压力、活塞密封，保持压力稳定。
- 气孔: 气孔在焊接时成为应力集中点，热影响区收缩时沿气孔开裂。需减少该区域气孔，提高致密度。同时，焊接工艺上采用预热、缓冷，减小热应力。
- 气孔形成: 磨损导致合模精度下降，分型面可能错位，产生飞边，同时气体易进入，形成气孔。需更换导柱导套，保持合模精度。
- 该区域质量: 说明气孔源于铸件本体。需返回压铸工序，优化该区域质量：调整高速起点，使焊接区避开气体聚集；加强冷却，提高致密度；控制铝液含气量。必要时改用低气孔率合金。
- 成为热节: 型芯冷却不足，局部过热，成为热节，产生缩孔。同时型芯易变形。需加强型芯冷却，如使用螺旋水道或点冷却。
- 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 补缩不足: 复合缺陷需分析主因：若缩孔为主，气孔为辅，则补缩不足是主因；反之，气体是主因。根据参数调整方向，改进工艺。
