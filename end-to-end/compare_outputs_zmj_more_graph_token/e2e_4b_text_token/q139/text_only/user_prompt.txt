四、检索文本：
- 分散区: 不规则气孔多为缩孔与气孔混合，或由卷气时气体被压缩变形。边缘模糊可能是微小缩松包围。需结合位置判断，若是热节区，则以缩孔为主；若是分散区，则以气孔为主。
- 水汽: 有影响。水基脱模剂易产生水汽，形成氢气孔；油基脱模剂可能产生碳氢气体。需选择发气量小的脱模剂，并控制喷涂量，避免积聚。高湿度环境下更应注意。
- 补缩通道: 异形截面处壁厚不均，形成多个热节，补缩路径复杂，易产生缩孔。需优化截面设计，尽量均匀壁厚，或增加补缩通道。
- 产生缩孔: 型芯偏心导致壁厚不均，薄处凝固快，厚处成为热节，产生缩孔。需保证型芯位置准确，避免偏移。
- 填充时间: 模温过高易导致脱模剂汽化、铝液吸气增加。应加强模具冷却，适当降低铝液温度，并提高高速速度缩短填充时间，减少气体吸收。同时检查排气槽是否通畅，必要时增加溢流槽。
- 卷气: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 形状规则: 气孔边缘光滑、形状规则（圆形或椭圆形），颜色均匀；缩孔边缘不规则、树枝状，颜色深浅不一（因密度变化）。有时需结合缺陷位置判断：热节区多为缩孔，分散区多为气孔。
