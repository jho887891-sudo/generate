【结论】当前样本应优先把分散气孔与卷气、分散区、补缩通道和慢速速度一起判断，当前主导矛盾更偏向分散气孔与卷气风险。

【溯源分析】
1. 区域证据描述分散气孔与卷气、分散区、补缩通道和慢速速度时，数量主导区域是慢速行程=525，风险关注区域是高速行程=205、高速时间=46、建压时间=114、铸造压力=926、压射压力=316。慢速行程较长时，铝液或气体更容易在慢速阶段停留，若同时高速切换不及时，会把分散气孔与卷气风险集中到高速行程、高速时间和建压时间相近位置。
2. 参数链是慢速速度= 0.19，高速速度 = 3.65，高速行程 = 205，高速时间 = 46，建压时间 = 114，铸造压力 = 926，压射压力 = 316。慢速速度决定铝液进入高速前的稳定状态，高速速度决定高速切换和充型稳定性；若慢速不稳或高速不一致，气体带入会同时影响分散气孔和卷气。
3. 区域风险与参数链共同作用后，慢速行程应作为分散气孔与卷气的观察起点，再由高速速度、高速行程和建压时间判断后续风险。

【建议方向】
1. 优先复核慢速行程、高速速度、高速行程和建压时间的前后样本一致性。
2. 用同料号、同模次或相近工况样本对照，观察慢速行程较长样本的分散气孔分布和高速切换一致性。
3. 后续验证应关注高速切换前后参数稳定性，而不能只看单一高速或单一慢速指标。
