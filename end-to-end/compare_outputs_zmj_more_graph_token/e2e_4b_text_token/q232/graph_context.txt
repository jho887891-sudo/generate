【图谱证据】
以下内容来自知识图谱检索，仅作为辅助证据与约束先验；若与当前样本统计冲突，必须以当前样本输入为准。
一、问题实体：
针对当前样本；主排查链；后段补偿链；辅助复核链
二、检索实体：
- 补缩
- 最后填充区
- 分散区
- 补缩通道
- 湿度高
- 射料结束位置
- 缩孔
- 形状规则
四、检索文本：
- 分散区: 不规则气孔多为缩孔与气孔混合，或由卷气时气体被压缩变形。边缘模糊可能是微小缩松包围。需结合位置判断，若是热节区，则以缩孔为主；若是分散区，则以气孔为主。
- 最后填充区: 通过模拟可预测最后填充区，即热节位置。调整高速起点，可移动热节。结合冷却系统，使热节处得到有效补缩。
- 补缩通道: 异形截面处壁厚不均，形成多个热节，补缩路径复杂，易产生缩孔。需优化截面设计，尽量均匀壁厚，或增加补缩通道。
- 现场可逐步后移射料结束位置，连续生产几模后探伤对比牙孔区域缩孔变化。找到缩孔最少的位置，即为最佳结束位置。注意不要过度后移导致材料浪费或飞边。
- 缩孔: 使用高导热材料 做镶块，加强热节处散热，减小缩孔。但成本高，需评估性价比。
- 气孔边缘光滑、形状规则，颜色均匀；缩孔边缘不规则、呈树枝状或锯齿状，颜色深浅不一。气孔多分散，缩孔多集中在热节区。结合位置可准确判断。
- 形状规则: 气孔边缘光滑、形状规则（圆形或椭圆形），颜色均匀；缩孔边缘不规则、树枝状，颜色深浅不一（因密度变化）。有时需结合缺陷位置判断：热节区多为缩孔，分散区多为气孔。
- 湿度高: 气孔多会导致渗透剂残留，影响检测判断。但湿度本身不影响检测，只是缺陷多。
- 射料结束位置: 射料结束位置决定了料饼厚度，而料饼厚度直接影响补缩压力的传递。如果结束位置太靠前，厚大区域无法得到有效补缩，缩孔出现；如果太靠后，虽然补缩改善，但可能浪费材料且不一定必要。因此，应通过试验确定既能有效补缩又不过度浪费的最佳结束位置。
- 补缩: 铜含量高，合金凝固范围窄，流动性好，有利于补缩，缩孔倾向小。但铜含量过高，热裂倾向大。需根据铸件要求选择合适的含铜合金。
