四、检索文本：
- 填充顺序: 高速行程主要影响填充顺序，与投影面积无直接关系。但投影面积大的铸件通常需要更长的填充时间，因此高速行程可能较长。需根据浇注系统设计来确定高速起点。
- 缩孔面积增大: 高速速度直接影响金属液的充填模式和流动前沿的稳定性。速度过快会导致喷射卷气，使气体进入焊接区域；速度过慢则可能使焊接区域充填时温度过低，产生冷隔或氧化夹杂，焊接时这些缺陷会暴露。因此，高速速度应优化到既能快速充满型腔，又不产生湍流，确保焊接区域质量。
- 高速速度过慢: 高速时间太长可能是由于高速行程过长或高速速度过慢。如果高速行程过长，意味着金属液过早高速，卷气风险增加；如果高速速度过慢，则填充时间过长，铝液降温，流动性变差，气体不易排出。两者都会导致分散性气孔增多。建议优化高速速度和高速起点，使高速时间既不过长也不过短，一般根据铸件壁厚和填充时间计算合理范围。
- 很小: 关联不大。慢速行程的时间在整个循环周期中占比很小，调整慢速速度对总节拍的影响可忽略。因此，可以放心优化慢速速度而不必担心生产效率。
- 在整个循环周期中: 关联不大。慢速行程的时间在整个循环周期中占比很小，调整慢速速度对总节拍的影响可忽略。因此，可以放心优化慢速速度而不必担心生产效率。
- 高速时间: 两者乘积固定时，可相互调整。例如，缩短高速行程同时提高高速速度，可保持高速时间不变。但需注意高速速度是否超限，高速行程是否合理。优化时应优先保证高速速度在安全范围。
- 金属液在压射室停留时间短: 慢速行程短意味着高速起点早，金属液在压射室停留时间短，温降小，有利于补缩。但若慢速过慢，可能仍导致卷气。综合来看，对缩孔影响较小，但需注意卷气引起的气缩孔。
- 卷气: 两者独立，但共同决定填充过程。慢速速度影响初始卷气和温降，高速速度影响填充时间和卷气。优化时需分别设定，确保慢速平稳、高速快速且不喷射。
- 高速速度: 两者独立，但共同决定填充过程。慢速速度影响初始卷气和温降，高速速度影响填充时间和卷气。优化时需分别设定，确保慢速平稳、高速快速且不喷射。
- 气孔: 高湿度下，脱模剂易吸水，润滑效果下降，可能导致粘模。同时，水汽产生气孔，使铸件表面粗糙，增加脱模阻力。需调整脱模剂配方或喷涂量。
