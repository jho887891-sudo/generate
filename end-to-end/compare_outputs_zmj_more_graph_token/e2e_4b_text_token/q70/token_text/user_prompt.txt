- 高速行程: 正常。高速行程决定了金属液开始高速填充的位置，直接影响气体的聚集区域。当高速起点改变时，气体被推动的路径和最终位置也会改变，因此集中性气孔的位置会相应移动。这正是通过调整高速行程将气体引入溢流槽的理论依据。现场可以逐步调整高速起点，观察气孔位置变化，找到最佳设置。
- 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 高速起点: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 建压时间长，缩孔可能更深（远离浇口），因压力无法传递到深处。建压时间短，缩孔浅，甚至消失。因此，控制建压时间可改变缩孔位置。
- 卷气: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 建压时间: 循环周期本身不直接影响建压时间，但周期长可能导致油温下降，液压油粘度变大，可能使建压时间略有延长。反之周期短油温高，建压时间可能缩短。但影响较小，主要保持油温稳定。
- 料饼厚度: 射料结束位置决定了料饼厚度，而料饼厚度直接影响补缩压力的传递。如果结束位置太靠前，厚大区域无法得到有效补缩，缩孔出现；如果太靠后，虽然补缩改善，但可能浪费材料且不一定必要。因此，应通过试验确定既能有效补缩又不过度浪费的最佳结束位置。
- 气体分布: 高速行程影响填充模式和气体分布，料饼厚度影响补缩压力传递。两者独立但共同决定最终质量。例如，高速行程使气体聚集某处，若该处补缩不足，则气缩孔严重。需协同优化。

- 有影响。慢速速度决定了金属液在压射室内的平稳程度。如果慢速过快导致卷气，这些气体会随金属液进入型腔，最终可能分布在包括焊接区域在内的各个部位。焊接时气体受热膨胀，形成焊接气孔或焊缝缺陷。因此，控制慢速速度是减少焊接区域气孔的基础措施之一。
