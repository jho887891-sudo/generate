四、检索文本：
- 最后填充: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 缩孔面积增大: 高速速度直接影响金属液的充填模式和流动前沿的稳定性。速度过快会导致喷射卷气，使气体进入焊接区域；速度过慢则可能使焊接区域充填时温度过低，产生冷隔或氧化夹杂，焊接时这些缺陷会暴露。因此，高速速度应优化到既能快速充满型腔，又不产生湍流，确保焊接区域质量。
- 局部冷却: 如果结构允许，优先在牙孔位置增加“锪孔”或“减肉”设计，消除局部热节，这是最彻底的解决方法。其次考虑调整参数：加强牙孔处的局部冷却、增大铸造压力、缩短建压时间、优化浇口使该区域得到充分补缩。参数调整见效快，但若热节过大，可能无法完全消除。
- 高速起点: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 热节: 如果结构允许，优先在牙孔位置增加“锪孔”或“减肉”设计，消除热节；其次考虑调整冷却，让牙孔处优先凝固；最后才考虑增大增压压力。单纯调参数往往难以根治局部热节造成的缩松。
- 高速起点晚: 高速行程短意味着高速起点晚，金属液在慢速阶段时间长，温度下降多。低温铝液进入型腔后，牙孔区域可能因流动性差而充填不完整，补缩通道提前凝固，形成缩孔。应适当提前高速起点，保证牙孔区域在合适温度下填充。
- 高速速度: 高速速度决定金属液通过内浇口的速度和填充模式。如果高速速度过快，在牙孔区域可能产生湍流卷气，形成气孔；如果过慢，牙孔区域充填时间过长，铝液降温，可能导致充填不完整，气体无法排出，同样形成气孔。因此，需要根据牙孔区域的结构优化高速速度，避免卷气且保证充填完整。
- 氢气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 结构允许: 如果结构允许，优先在牙孔位置增加“锪孔”或“减肉”设计，消除热节；其次考虑调整冷却，让牙孔处优先凝固；最后才考虑增大增压压力。单纯调参数往往难以根治局部热节造成的缩松。
- 气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
