四、检索文本：
- 湿度高: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 热节: 如果结构允许，优先在牙孔位置增加“锪孔”或“减肉”设计，消除局部热节，这是最彻底的解决方法。其次考虑调整参数：加强牙孔处的局部冷却、增大铸造压力、缩短建压时间、优化浇口使该区域得到充分补缩。参数调整见效快，但若热节过大，可能无法完全消除。
- 该区域最佳值: 逐步后移高速起点或前移，每改变一次生产几模，探伤对比牙孔区域气孔变化。找到气孔最少的高速起点，即为该区域的最佳值。注意同时观察其他区域是否变差。
- 缩孔: 射料结束位置决定了最终留在压室内的料饼厚度。位置太靠前意味着料饼过薄，无法为铸件提供足够的补缩压力。牙孔区域往往需要后期压力压实，一旦压力中断，该区域就会产生缩孔。此外，薄料饼还可能导致建压时间延长，进一步削弱补缩效果。现场应逐步后移结束位置，增加料饼厚度，观察缩孔改善情况。
- 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 气孔: 比值决定金属液从慢速到高速的过渡平稳性。比值不当易在切换点产生卷气。一般推荐慢速临界速度以下，高速速度根据浇口面积计算，确保切换时金属液已到达内浇口且无波动。通过模拟或经验优化比值可减少气孔。
- 形成气孔: 压射压力影响充填阶段的流动状态。如果压射压力不足，可能导致牙孔区域充填不完整，气体无法被推出，形成气孔；如果压力过高，可能引起喷射卷气。因此，合适的压射压力有助于平稳充填，减少气孔。但气孔的消除还需结合高速速度和排气设计。
- 气孔在焊接时成为应力集中点，热影响区收缩时沿气孔开裂。需减少该区域气孔，提高致密度。同时，焊接工艺上采用预热、缓冷，减小热应力。
- 卷气: 慢速行程短意味着高速起点早，金属液过早进入高速阶段。这可能导致铝液在压射室内停留时间不足，温度较高，但同时也可能因高速过早引起卷气。如果卷气产生的气体最终聚集在牙孔区域，就会形成气孔；而缩孔增多则可能是因为高速过早导致填充模式变化，使牙孔区域补缩不足。实际上，慢速行程应与慢速速度匹配，保证金属液平稳推进到内浇口。
