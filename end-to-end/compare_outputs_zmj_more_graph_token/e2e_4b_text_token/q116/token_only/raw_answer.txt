【结论】当前样本应优先按高速充型稳定性来判断整体卷气风险，而不是只看局部顶杆或浇口附近；当前主导矛盾更偏向高速阶段的气体卷入，把高速行程、高速速度和建压时间作为同源诊断起点。

【溯源分析】
1. 区域证据只支持判断视觉分布集中区域，不能代替缺陷分布或缺陷成因。当前样本把高速行程作为视觉关注起点，说明当前判断应优先围绕高速充型阶段的稳定性分布。
2. 从参数链看，高速速度决定高速阶段的持续时间和卷气风险，高速行程决定高速段是否平稳，建压时间决定增压前的充型稳定性，三者共同决定高速阶段气体带入规模。
3. 视觉层把高速行程作为当前关注起点，说明当前样本更应把高速充型稳定性作为比局部缺陷更容易复现的共同依据。

【建议方向】
1. 先固定其他参数，单独观察高速速度、高速行程和建压时间变化时，高速段是否平稳。
2. 复核时应把高速行程曲线与局部顶杆/浇口风险同时观察，确认是局部热气柱问题还是整体高速阶段不稳。
3. 后续样本若出现相近工况，应把高速速度、高速行程和建压时间作为对照参数，判断缺陷是否同时向相近区域扩散。
