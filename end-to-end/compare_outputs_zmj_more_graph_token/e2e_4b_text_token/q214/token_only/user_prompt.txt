四、检索文本：
- 缩孔: 在厚大区域设置挤压销，在凝固后期启动，施加局部压力补缩，消除缩孔。挤压销直径、位置和启动时间需优化，通常通过模拟确定。可有效解决孤立缩孔。
- 气体聚集: 可能该区域是热节或最后填充区。作为热节，缩孔倾向大；作为最后填充区，气体聚集，气孔多。两者叠加导致缺陷面积大。需针对具体原因优化：若热节则加强冷却，若最后填充则调整高速起点。
- <厚大区域: 厚大区域对温度敏感。温度高时，缩孔倾向大，应加强冷却并增大铸造压力；温度低时，缩孔可能减少但气孔增加，需平衡。一般控制在工艺中限，并根据缺陷类型微调。
- 循环周期短: 循环周期影响模温。如果周期短，模温高，牙孔区域过热，缩孔倾向增加，缺陷面积可能增大。如果周期长，模温低，可能导致充填不良，气孔增多。因此，稳定的周期有助于控制缺陷面积。
- 高速行程: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 高速起点: 经验公式：高速起点 = 料饼厚度 + 浇注系统体积对应的行程。浇注系统体积包括直浇道、横浇道、内浇口。计算后通过试模修正。
- 该区域最佳值: 逐步后移高速起点或前移，每改变一次生产几模，探伤对比牙孔区域气孔变化。找到气孔最少的高速起点，即为该区域的最佳值。注意同时观察其他区域是否变差。
- 卷气: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 缩孔倾向大: 可能该区域是热节或最后填充区。作为热节，缩孔倾向大；作为最后填充区，气体聚集，气孔多。两者叠加导致缺陷面积大。需针对具体原因优化：若热节则加强冷却，若最后填充则调整高速起点。
- 射料结束位置: 现场可逐步后移射料结束位置，连续生产几模后探伤对比牙孔区域缩孔变化。找到缩孔最少的位置，即为最佳结束位置。注意不要过度后移导致材料浪费或飞边。
