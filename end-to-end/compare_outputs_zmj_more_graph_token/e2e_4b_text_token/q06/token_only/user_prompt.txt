四、检索文本：
- 湿度高: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 流动顺畅: 直角转弯处金属液冲击，产生涡流卷气，形成气孔。同时压力损失。需改为圆角过渡，使流动顺畅。
- 补缩困难: 圆角处若半径过小，形成应力集中，同时可能成为热节，补缩困难，产生缩孔。需加大圆角半径，减少热节，使应力分散，补缩顺畅。
- 气孔: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 牙孔区域过热: 高速时间即填充时间，应小于允许的最长填充时间（根据壁厚计算）。一般薄壁件填充时间短，厚壁件可稍长。若高速时间过长，易降温导致缩孔；过短易卷气。需通过模拟或经验确定合理范围。
- 壁厚突变处形成热节，凝固时收缩无补缩来源，产生集中缩孔。厚大区域最后凝固，若压力不足，缩孔严重。设计时应尽量均匀壁厚，4. 铝液精炼除气不彻底，会产生什么类型的气孔？      除气不彻底导致铝液含氢量高，凝固时析出细小分散的氢气孔，探伤呈针孔状或星点状，常见于厚大区域。需加强精炼工艺，使用旋转除气或氮气吹洗，控制含氢量。
- 形成气孔: 铝液温度越高，氢气溶解度越大。凝固时溶解度骤降，过饱和氢气析出形成气孔。因此，高温铝液易产生氢气孔。控制铝液温度在工艺下限，并加强除气，可减少氢气孔。
- 最后填充: 增大铸造压力，缩短建压时间，提高料饼厚度，加强局部冷却。同时优化高速起点，使厚大区域避开最后填充，或使其在增压前充满。
- 厚大区域: 蜂窝状缩孔是密集的微小缩松，由补缩不足和合金凝固范围宽引起。常见于厚大区域。需提高铸造压力，加强冷却，或改变合金成分。
- 内浇口已凝固: 非常大。牙孔区域往往是加工后暴露的内部区域，如果建压时间过长，增压压力到达时内浇口已凝固，该区域无法获得补缩，必然产生缩孔或疏松。即使铸造压力很大，也无法弥补时间上的滞后。因此，牙孔区域的质量对建压时间极为敏感，必须确保建压时间远小于该区域凝固时间。
