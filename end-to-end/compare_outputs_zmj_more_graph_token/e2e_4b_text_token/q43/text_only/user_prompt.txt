四、检索文本：
- 压射压力: 压射压力影响充填流速，进而影响气体聚集位置。适当调整压射压力可以微调气孔位置，但不能根治。优化时应以高速参数为主，压力为辅。例如，先调高速起点将气体引入溢流槽，再调压力确保平稳填充。
- 最后填充: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 牙孔区域: 直接影响。牙孔区域通常需要足够的铸造压力来压实补缩。如果铸造压力不足，该区域在凝固时无法得到有效补缩，就会形成缩孔。但前提是压力必须能在内浇口凝固前传递进去，否则压力再大也无用。
- 足够的铸造压力: 直接影响。牙孔区域通常需要足够的铸造压力来压实补缩。如果铸造压力不足，该区域在凝固时无法得到有效补缩，就会形成缩孔。但前提是压力必须能在内浇口凝固前传递进去，否则压力再大也无用。
- 缩孔: 射料结束位置决定了最终留在压室内的料饼厚度。位置太靠前意味着料饼过薄，无法为铸件提供足够的补缩压力。牙孔区域往往需要后期压力压实，一旦压力中断，该区域就会产生缩孔。此外，薄料饼还可能导致建压时间延长，进一步削弱补缩效果。现场应逐步后移结束位置，增加料饼厚度，观察缩孔改善情况。
- 形成缩孔: 建压时间变长意味着从充填结束到建立最终铸造压力的时间间隔过长。在这段时间内，内浇口可能已经部分或完全凝固，导致增压压力无法有效传递到型腔内部的厚大区域。厚大区域由于最后凝固，如果没有足够的压力补缩，就会形成明显的缩孔。现场应检查液压系统响应、氮气压力，并尽可能缩短建压时间。
- 补缩效果充分否: 铸造压力是增压阶段的最终目标压力，建压时间是从压射压力上升到铸造压力所需的时间。两者共同决定补缩效果：即使铸造压力很大，如果建压时间过长，压力到达时浇口已凝固，补缩无效；反之，建压时间短但压力不足，补缩也不充分。因此，需要同时优化这两个参数。
- 气体聚集: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 气孔: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 组织更致密: 铸造压力直接影响铸件的致密度。较高的铸造压力可以使焊接区域的组织更致密，减少微观缩松，从而降低焊接时气体逸出的风险。但铸造压力不能解决卷气问题。如果焊接区域本身有气孔，压力只能压缩而不能消除。因此，需要结合其他参数共同优化。
