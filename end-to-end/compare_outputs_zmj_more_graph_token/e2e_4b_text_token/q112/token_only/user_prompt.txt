四、检索文本：
- 慢速速度过快: 增加高速速度可缩短填充时间，减少温降，有利于补缩。但速度过快可能卷气，需平衡。适当提速可改善缩孔。
- 补缩不足: 压射室磨损会导致冲头与压室间隙增大，金属液在慢速阶段可能从间隙中泄漏或卷气，增加气孔风险。同时，压力损失使补缩不足，加剧缩孔。需定期检查压室直径，更换磨损件。
- 补缩通道: 异形截面处壁厚不均，形成多个热节，补缩路径复杂，易产生缩孔。需优化截面设计，尽量均匀壁厚，或增加补缩通道。
- 形成缩孔: 根本原因是厚大区域是热节，凝固速度最慢。在凝固过程中，体积收缩需要补缩，如果补缩压力不足或补缩通道不畅，就会形成缩孔。同时，最后凝固的区域也是气体析出聚集的地方。因此，厚大区域容易同时出现缩孔和气孔，形成复合缺陷。解决思路是加强冷却、优化补缩和排气。
- 厚大区域: 这是典型的气缩孔复合缺陷。厚大区域凝固时间长，一方面铝液中的氢气在凝固过程中析出，形成细小氢气孔；另一方面，如果补缩不足，产生缩孔。同时，如果慢速卷气产生的气泡在浮力作用下也可能上浮聚集在厚大区域。因此，缩孔周围常伴有细小气孔。解决需同时改善铝液质量和补缩条件。
- 产生缩孔或疏松: 非常大。牙孔区域往往是加工后暴露的内部区域，如果建压时间过长，增压压力到达时内浇口已凝固，该区域无法获得补缩，必然产生缩孔或疏松。即使铸造压力很大，也无法弥补时间上的滞后。因此，牙孔区域的质量对建压时间极为敏感，必须确保建压时间远小于该区域凝固时间。
- 高速速度: 高速速度下降，填充时间延长，铝液降温，可能导致补缩通道提前凝固，缩孔增加。需检查液压系统、氮气压力，恢复速度。轻微下降可能影响不大，但需监控，避免持续恶化。
- 合适的结束位置: 直接影响。结束位置决定料饼厚度，进而影响最终补缩压力能否到达集中缩孔区域。合适的结束位置能保证压力有效传递，减少集中缩孔。
- 无法获得补缩: 非常大。牙孔区域往往是加工后暴露的内部区域，如果建压时间过长，增压压力到达时内浇口已凝固，该区域无法获得补缩，必然产生缩孔或疏松。即使铸造压力很大，也无法弥补时间上的滞后。因此，牙孔区域的质量对建压时间极为敏感，必须确保建压时间远小于该区域凝固时间。
- 建压时间延长: 氮气压力降低，增压器响应变慢，建压时间延长，导致补缩失效，缩孔增加。需立即补充氮气至规定值，并检查是否有泄漏。定期检查氮气压力是日常维护重点。
