四、检索文本：
- 压力损失: 压射室磨损会导致冲头与压室间隙增大，金属液在慢速阶段可能从间隙中泄漏或卷气，增加气孔风险。同时，压力损失使补缩不足，加剧缩孔。需定期检查压室直径，更换磨损件。
- 填充模式变化: 慢速行程短意味着高速起点早，金属液过早进入高速阶段。这可能导致铝液在压射室内停留时间不足，温度较高，但同时也可能因高速过早引起卷气。如果卷气产生的气体最终聚集在牙孔区域，就会形成气孔；而缩孔增多则可能是因为高速过早导致填充模式变化，使牙孔区域补缩不足。实际上，慢速行程应与慢速速度匹配，保证金属液平稳推进到内浇口。
- 缩孔增多: 慢速行程短意味着高速起点早，金属液过早进入高速阶段。这可能导致铝液在压射室内停留时间不足，温度较高，但同时也可能因高速过早引起卷气。如果卷气产生的气体最终聚集在牙孔区域，就会形成气孔；而缩孔增多则可能是因为高速过早导致填充模式变化，使牙孔区域补缩不足。实际上，慢速行程应与慢速速度匹配，保证金属液平稳推进到内浇口。
- 卷气: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 涡流: 高速时间太短（速度很快）可能导致喷射卷气，气体被推到厚大区域形成气孔。同时，速度过快也可能使厚大区域填充时产生涡流，卷入气体。应降低高速速度，避免喷射。
- 压射压力: 压射压力影响充填流速，进而影响气体聚集位置。适当调整压射压力可以微调气孔位置，但不能根治。优化时应以高速参数为主，压力为辅。例如，先调高速起点将气体引入溢流槽，再调压力确保平稳填充。
- 高速速度: 高速速度决定金属液通过内浇口的速度和填充模式。如果高速速度过快，在牙孔区域可能产生湍流卷气，形成气孔；如果过慢，牙孔区域充填时间过长，铝液降温，可能导致充填不完整，气体无法排出，同样形成气孔。因此，需要根据牙孔区域的结构优化高速速度，避免卷气且保证充填完整。
- 气孔: 压射压力增大会改变金属液的流速和填充模式。流速增加可能使气体被推到更远的位置，或者原本聚集的气体被冲散，导致气孔位置移动或形态变化。但压力本身并不直接消除气孔，只是改变了分布。要彻底解决集中气孔，仍需优化高速参数和排气系统。
- 高速行程: 建议优先检查浇注系统和排气系统。因为两个不同位置同时出现气孔，大概率是整体填充模式不良导致的卷气或困气。建议先做填充模拟或空射试验观察铝液流动是否顺畅，再调整高速起点和排气块。
