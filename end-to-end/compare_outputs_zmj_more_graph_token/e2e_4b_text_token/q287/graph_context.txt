- 气体的聚集区域: 正常。高速行程决定了金属液开始高速填充的位置，直接影响气体的聚集区域。当高速起点改变时，气体被推动的路径和最终位置也会改变，因此集中性气孔的位置会相应移动。这正是通过调整高速行程将气体引入溢流槽的理论依据。现场可以逐步调整高速起点，观察气孔位置变化，找到最佳设置。
- 调整高速速度: 首先确定气孔类型。如果是氢气孔，需加强铝液除气和降低湿度；如果是卷气孔，则调整高速速度和高速起点，避免气体聚集在厚大区域；如果是气缩混合孔，则需同时改善补缩。具体调整：①优化高速起点，让气体被推至溢流槽；②加强厚大区域的局部冷却，使气体在凝固前有更多时间排出；③适当降低浇注温度，减少气体析出。
- 湿度高: 高速速度直接影响金属液的充填模式和流动前沿的稳定性。速度过快会导致喷射卷气，使气体进入焊接区域；速度过慢则可能使焊接区域充填时温度过低，产生冷隔或氧化夹杂，焊接时这些缺陷会暴露。因此，高速速度应优化到既能快速充满型腔，又不产生湍流，确保焊接区域质量。
- 加强局部冷却: 首先确定气孔类型。如果是氢气孔，需加强铝液除气和降低湿度；如果是卷气孔，则调整高速速度和高速起点，避免气体聚集在厚大区域；如果是气缩混合孔，则需同时改善补缩。具体调整：①优化高速起点，让气体被推至溢流槽；②加强厚大区域的局部冷却，使气体在凝固前有更多时间排出；③适当降低浇注温度，减少气体析出。
- 气体的聚集位置: 可能。高速速度改变会影响气体的聚集位置。原来分散的气体可能在新速度下被推到某一特定区域（如死角），形成集中气孔。这说明虽然总气量可能没变，但分布变了。此时应进一步调整高速起点或排气系统，将气体引导至溢流槽，而不是简单调整速度。
- 总行程: 两者之和为总行程。调整高速起点会同时改变两者，需综合考虑对填充模式的影响。
- 增加高速速度: 增加高速速度会使填充时间缩短，可能减少降温，但易引起喷射卷气，导致气孔增多且可能更分散。若原速度较低，适当提速可改善充填；若已较高，提速则恶化。需结合浇口速度临界值判断。
