四、检索文本：
- 填充时间: 模温过高易导致脱模剂汽化、铝液吸气增加。应加强模具冷却，适当降低铝液温度，并提高高速速度缩短填充时间，减少气体吸收。同时检查排气槽是否通畅，必要时增加溢流槽。
- 湿度高时，应适当优化高速速度以减少湍流卷气，避免将潮湿空气卷入。但高速速度本身不直接受湿度影响，主要是工艺上需更精细控制，防止卷气带入水汽。
- 卷气: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 过多水分: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 减少吸气: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 加强铝液除气: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 气孔: 高湿度下，脱模剂易吸水，润滑效果下降，可能导致粘模。同时，水汽产生气孔，使铸件表面粗糙，增加脱模阻力。需调整脱模剂配方或喷涂量。
- 慢速速度过快: 湿度高时，铝液吸氢严重，氢气在凝固过程中溶解度降低，会优先在最后凝固的厚大区域析出并聚集，形成集中性氢气孔。这些气孔往往与缩孔混合，形成气缩孔，加剧缺陷严重性。因此，在高湿度环境下，厚大区域更容易出现气孔，需要加强除气、排气和冷却。
- 高速速度: 两者独立，但共同决定填充过程。慢速速度影响初始卷气和温降，高速速度影响填充时间和卷气。优化时需分别设定，确保慢速平稳、高速快速且不喷射。
- 铝液: 高湿度时，慢速速度应尽可能低以减少卷气带入水汽，但需平衡温降。通常在高湿季节，建议将慢速速度调至临界值下限，并加强铝液除气，同时检查脱模剂含水量，避免额外水分。
