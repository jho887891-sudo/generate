四、检索文本：
- 气体聚集: 可能该区域是热节或最后填充区。作为热节，缩孔倾向大；作为最后填充区，气体聚集，气孔多。两者叠加导致缺陷面积大。需针对具体原因优化：若热节则加强冷却，若最后填充则调整高速起点。
- 加强冷却: 气孔导致材料缺失，加工时刀具可能偏向缺陷，或气孔处强度低，加工后变形。需先解决气孔问题，同时检查加工余量是否过大。优化参数减少该区域气孔，如加强冷却、调整高速。
- 增大铸造压力: 缩孔导致螺纹强度不足。应优先增大铸造压力、缩短建压时间，确保补缩。同时检查牙孔处是否有热节，加强点冷。若仍无效，考虑增加局部挤压销或改变浇口位置。
- 高速起点: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 铸造压力: 铸造压力直接影响铸件的致密度。较高的铸造压力可以使焊接区域的组织更致密，减少微观缩松，从而降低焊接时气体逸出的风险。但铸造压力不能解决卷气问题。如果焊接区域本身有气孔，压力只能压缩而不能消除。因此，需要结合其他参数共同优化。
- 气孔增多: 周期缩短使模具吸热增多，模温上升，可能导致脱模剂失效、粘模、气孔增多（因气体膨胀）、缩孔增大（因凝固慢）。需同步调整冷却水流量或时间，维持模温稳定，必要时增加点冷。
- 缩孔倾向大: 可能该区域是热节或最后填充区。作为热节，缩孔倾向大；作为最后填充区，气体聚集，气孔多。两者叠加导致缺陷面积大。需针对具体原因优化：若热节则加强冷却，若最后填充则调整高速起点。
- 气孔: 根本原因是厚大区域是热节，凝固速度最慢。在凝固过程中，体积收缩需要补缩，如果补缩压力不足或补缩通道不畅，就会形成缩孔。同时，最后凝固的区域也是气体析出聚集的地方。因此，厚大区域容易同时出现缩孔和气孔，形成复合缺陷。解决思路是加强冷却、优化补缩和排气。
- 湿度高: 气孔多会导致渗透剂残留，影响检测判断。但湿度本身不影响检测，只是缺陷多。
- 铸件致密度: 有一定改善作用。较高的铸造压力可以将部分微小气孔压缩变小，甚至使气孔闭合，从而提高铸件致密度。但压力不能消除气孔产生的根源，因此改善程度有限。如果气孔很大或很多，单纯依靠压力无法根治，仍需从源头上减少气体卷入。
