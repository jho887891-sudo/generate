四、检索文本：
- 湿度高: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 作为热节: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
- 补缩: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
- 加强冷却: 气孔导致材料缺失，加工时刀具可能偏向缺陷，或气孔处强度低，加工后变形。需先解决气孔问题，同时检查加工余量是否过大。优化参数减少该区域气孔，如加强冷却、调整高速。
- 氢气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 牙孔区域: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。

- 气孔: 气孔在焊接时成为应力集中点，热影响区收缩时沿气孔开裂。需减少该区域气孔，提高致密度。同时，焊接工艺上采用预热、缓冷，减小热应力。
- 气体: 可在牙孔附近增加溢流槽，收集气体；或改变浇口位置，使牙孔区域优先填充；或增加局部挤压销。同时，加强牙孔处冷却，减小热节。模具修改需结合模拟。
