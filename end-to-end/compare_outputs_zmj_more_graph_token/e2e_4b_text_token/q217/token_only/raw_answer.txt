【结论】当前样本应优先把高速速度作为气孔风险主因，同时关注高速行程、高速时间、建压时间和铸造压力的连锁变化。

【溯源分析】
1. 当前样本把高速速度作为当前关注重点，是把参数链与区域分布结合起来判断时，比只看单一参数或只看缺陷分布更有效的判断依据。高速速度决定金属液进入型腔后的流动状态，直接影响卷气和气孔分布。当前样本的高速速度为3.65，高速行程为205，高速时间为46，若高速起点偏后或浇道/浇口位置不稳，高速阶段会把气体带入厚大区，形成局部气孔。慢速速度为0.19，慢速行程为525，慢速阶段主要决定金属液进入型腔前的稳定状态，若慢速不稳，会把气体带入高速阶段，使高速阶段更容易卷气。
2. 从参数链看，高速速度影响高速行程、高速时间、建压时间、压射压力和铸造压力的调节一致性。高速速度为3.65时，高速行程为205，高速时间为46，建压时间为114，压射压力为316，铸造压力为926。高速速度主要决定高速阶段的持续时间和金属液前沿稳定性；若高速速度偏低，金属液可能无法及时建立稳定充填，同时慢速阶段的气体可能被带入高速阶段；若高速速度偏高，金属液前沿容易不稳，产生湍流或喷射，把气体卷入型腔内部。高速行程和高速时间可反映高速阶段的分布，若两者与高速速度不匹配，说明高速起点或高速过渡需要调整。
3. 当前样本把高速速度作为风险主因，是把缺陷分布与参数链结合起来时比只看缺陷数量或只看参数值更可靠的判断。缺陷分布可快速识别出气孔集中区域，参数链可解释原因；若某一块区域气孔明显比相邻区域多，说明该区域的高速充型或建压状态需要单独判断；若高速速度变化前后，气孔位置或数量没有同步变化，说明其他参数如慢速稳定性或排气状态可能更重要。

【建议方向】
1. 先固定慢速阶段，单独观察高速速度变化对气孔分布的影响，再判断是否需要同时调整高速行程或建压时间。
2. 用同料号、同模次或相近工况样本对照，观察高速速度单独变化时，气孔分布是否同步变化。
3. 后续验证应关注高速速度调整后，高速行程、高速时间、建压时间和铸造压力是否同步改善，而不仅看缺陷数量是否减少。
