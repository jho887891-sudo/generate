【结论】当前样本应优先把高速起点作为区域化诊断的起点，再判断高速速度、高速时间和铸造压力的匹配状态。

【溯源分析】
1. 区域统计和缺陷分布决定了当前诊断的起点：当前样本把高速起点作为诊断起点，说明前沿卷气风险应与高速起点位置和高速行程匹配判断。慢速行程短说明高速起点早，金属液过早进入高速阶段，若同时高速速度或高速时间不稳定，更容易把卷气集中到厚大区域或热节附近。
2. 高速充型、建压、压射压力和铸造压力的物理链路是：高速起点决定金属液进入高速阶段的位置，高速速度决定高速行程和高速时间，高速时间影响金属液前沿稳定性、温度和卷气风险，建压时间决定金属液进入型腔后的补压状态，铸造压力决定缺陷是否能被压实。三者共同决定缺陷是否能被有效压缩或转移。
3. 当前样本的区域风险应与参数链共同排序：当前样本不能只看卷气发生位置，还要看高速起点是否把厚大区域或热缝区域提前暴露。参数链优先级应是高速起点 → 高速速度 → 高速时间 → 建压时间 → 铸造压力。

【建议方向】
1. 先固定其他参数，单独观察高速起点变化对前沿卷气的直接影响。
2. 用同料号、同模次或相近工况样本对照，观察高速起点靠近热缝或厚大区域时，卷气分布是否集中。
3. 后续验证应关注高速起点前后参数的连续变化，而不仅限于卷气位置的静态描述。
