四、检索文本：
- 高速速度: 高速时间由高速行程和高速速度决定，射料结束位置是高速的终点。因此，结束位置固定时，高速时间取决于高速速度和起点。调整结束位置会影响高速行程，从而影响高速时间。
- 高速时间 = 高速行程 / 高速速度。在高速速度固定时，高速行程越长，高速时间越长；反之越短。两者共同决定填充时间，需根据铸件壁厚和工艺要求匹配。
- 高速行程影响最后填充区，该区模温较高。通过调整高速行程，可改变高温区位置，配合冷却系统，使模温均匀。
- 高速时间 = 高速行程 / 高速速度。三者相互关联，调整任何一个都会影响另外两个。优化时需综合考虑铸件结构和填充时间要求。
- 两者乘积固定时，可相互调整。例如，缩短高速行程同时提高高速速度，可保持高速时间不变。但需注意高速速度是否超限，高速行程是否合理。优化时应优先保证高速速度在安全范围。
- 高速时间: 高速速度设定后，需确保压射压力足够达到该速度。通常通过压射曲线观察实际速度是否与设定一致，如有偏差则调整压力。
