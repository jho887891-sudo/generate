四、检索文本：
- 填充不稳定: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 湿度高: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 牙孔区域: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 撇渣: 氧化膜在浇注过程中卷入铝液，形成夹杂。夹杂周围易吸附气体，成为气泡核心，同时破坏补缩通道，引发缩孔。需通过撇渣、过滤等方式去除氧化膜。
- 形成气孔: 高湿度下，脱模剂可能吸湿，喷涂时水分增多，遇到铝液产生大量气体，形成气孔。应使用高浓度脱模剂，减少喷涂量，并确保压缩空气干燥。同时加强排气，避免气体滞留。
- 该区域质量: 说明气孔源于铸件本体。需返回压铸工序，优化该区域质量：调整高速起点，使焊接区避开气体聚集；加强冷却，提高致密度；控制铝液含气量。必要时改用低气孔率合金。
- 高湿度环境下: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 最可能的原因: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
- 大面积气孔: 最可能的原因是牙孔区域既是热节，又是气体聚集区。作为热节，它需要补缩，如果压力传递不畅，就会形成大面积缩孔；作为气体聚集区，如果填充模式不良，气体被推到此处无法排出，则形成大面积气孔。两者往往同时发生，形成气缩孔。应对措施包括优化浇注系统使该区域避开最后填充、加强局部冷却、增大铸造压力等。
- 气孔: 浇口对面常是最后填充区，气体聚集形成气孔。需调整高速起点，使气体在到达对面之前排入溢流槽。或在该处增加排气。
