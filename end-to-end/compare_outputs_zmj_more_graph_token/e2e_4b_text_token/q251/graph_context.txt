四、检索文本：
- 高速起点: 经验公式：高速起点 = 料饼厚度 + 浇注系统体积对应的行程。浇注系统体积包括直浇道、横浇道、内浇口。计算后通过试模修正。
- 热节: 通过模拟可预测最后填充区，即热节位置。调整高速起点，可移动热节。结合冷却系统，使热节处得到有效补缩。
- 高速行程: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 慢速速度慢: 慢速速度慢，金属液流速低，对模具冲蚀小。但若卷气，气泡冲击模具也可能引起冲蚀。总体上，慢速对模具寿命影响较小，高速段是冲蚀主因。
- 高速填充阶段: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 最后填充区: 通过模拟可预测最后填充区，即热节位置。调整高速起点，可移动热节。结合冷却系统，使热节处得到有效补缩。
- 高速行程影响填充方向，从而影响流线分布。合理的流线应顺着铸件形状，避免涡流。若高速起点不当，流线紊乱，可能产生气孔和裂纹。
- 热节位置: 通过模拟可预测最后填充区，即热节位置。调整高速起点，可移动热节。结合冷却系统，使热节处得到有效补缩。
- 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
- 初始含气量: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
