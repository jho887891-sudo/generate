【结论】当前样本应优先判断气孔主因是否可拆出单一参数异常，而不是只看缺陷分布。当前主导风险更偏向高速充型阶段的卷气风险，应优先把高速起点、高速行程、高速时间与气孔位置关联判断。

【溯源分析】
1. 区域证据只保留视觉/区域前缀对应的缺陷分布，用于判断缺陷在样本中呈现的区域和数量。视觉/区域前缀对应当前样本的高速行程= 205，说明当前样本关注高速充型过程；若某块区域连续出现气孔，说明该区域更容易把高速充型卷入气孔主链。
2. 参数链应从高速充型、建压、补压和铸造压力角度解释。高速行程= 高速时间.高速速度.建压时间.铸造压力.铸造压力的调节顺序决定金属液进入型腔后气体卷入和补压补压状态。若缺陷在高速切换或建压后快速出现，说明高速或建压参数链需要优先复核。
3. 区域证据和参数链不能割裂，区域缺陷只能作为参数链的观察佐证，不能代替参数本身原因判断。参数异常可能只影响局部，区域分布只能说明风险集中区域，但主因仍需回到参数链中复核。

【建议方向】
1. 优先复核高速行程、高速时间、高速速度和建压时间的参数链，观察高速切换和建压后的气孔变化。
2. 复核区域分布是否与高速或建压参数吻合，区域集中时优先把高速或建压作为更高一级的误差放大器。
3. 用同料号、同模次、同模次相近样本的气孔分布和参数同步变化，判断是局部异常还是系统性风险放大。
