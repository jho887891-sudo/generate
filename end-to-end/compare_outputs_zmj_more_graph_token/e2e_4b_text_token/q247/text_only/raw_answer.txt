【结论】
当前样本的当前主因应同时看数量主导区域一般区域和风险关注区域牙孔区域，两个区域共同决定当前问题的暴露程度。

【溯源分析】
1. 一般区域数量最多，说明该区域更容易出现分布性缺陷；牙孔区域最大面积和最大等效直径都更高，说明该区域更容易出现单点集中风险。一般区域数量主导，牙孔区域面积和尺寸风险关注，两个区域不能简单按数量多少排序。
2. 一般区域数量多，说明慢速阶段或低速填充阶段的卷气倾向需要关注；牙孔区域最大面积和最大等效直径高，说明高速或建压阶段需要把热平衡和压力传递作为更高优先级。参数链为慢速行程 → 高速起点 → 建压时间 → 高速速度 → 高速行程 → 压射压力 → 铸造压力。
3. 一般区域数量多时，缺陷更容易随样本分布变化；牙孔区域最大面积或最大等效直径突出时，缺陷更容易随高速或建压参数变化而变化。因此判断应先看一般区域数量，再看牙孔区域的最大面积或最大等效直径。

【建议方向】
1. 先以一般区域数量作为分布风险指标，再以牙孔区域的最大面积或最大等效直径作为单点风险指标，两个维度共同判断缺陷分布和极值暴露。
2. 复核时应分别统计一般区域数量和牙孔区域最大面积/直径，观察整体分布和单点极值是否同时收敛。
3. 同料号、同视角、同工况样本应分别按一般区域数量和牙孔区域极值做对照，确认是局部热平衡问题还是整体分布问题在主导。
