四、检索文本：
- 铝液降温: 高速速度影响填充时间和温度场。速度过快，填充时间短，但可能卷气；速度过慢，填充时间长，铝液降温，导致补缩通道提前凝固，缩孔增加。因此，合适的高速速度需平衡卷气和降温。
- 牙孔区域过热: 高速时间即填充时间，应小于允许的最长填充时间（根据壁厚计算）。一般薄壁件填充时间短，厚壁件可稍长。若高速时间过长，易降温导致缩孔；过短易卷气。需通过模拟或经验确定合理范围。
- 形成气孔: 高速行程过长意味着高速起点过早，金属液在较早就进入高速填充阶段。此时如果内浇口速度过高，容易卷气；同时，过早高速会使金属液在型腔内快速推进，气体可能被推到厚大区域并聚集。当气体无法排出时，就在厚大区域形成气孔。优化方法是逐步推迟高速起点，让气体有更多时间从排气槽排出。
- 高速速度过快: 浇口附近云雾状气孔通常由金属液通过内浇口时产生喷射卷气所致。高速速度过快或内浇口截面积过小，导致浇口速度超过临界值，金属液雾化卷入大量气体。需降低高速速度或加大内浇口截面积，同时检查浇口形状是否导致流线紊乱。
- 慢速速度: 慢速速度影响卷入气体的方式。慢速过快，气孔多而小，呈分散状；慢速适中，气孔少；慢速过慢，可能产生大卷气团。因此，慢速影响气孔大小和分布。
- 料饼厚度: 射料结束位置决定了料饼厚度，而料饼厚度直接影响补缩压力的传递。如果结束位置太靠前，厚大区域无法得到有效补缩，缩孔出现；如果太靠后，虽然补缩改善，但可能浪费材料且不一定必要。因此，应通过试验确定既能有效补缩又不过度浪费的最佳结束位置。
- 高速速度: 高速速度决定金属液通过内浇口的速度和填充模式。如果高速速度过快，在牙孔区域可能产生湍流卷气，形成气孔；如果过慢，牙孔区域充填时间过长，铝液降温，可能导致充填不完整，气体无法排出，同样形成气孔。因此，需要根据牙孔区域的结构优化高速速度，避免卷气且保证充填完整。
- 气孔: 高速速度决定金属液通过内浇口的速度和填充模式。如果高速速度过快，在牙孔区域可能产生湍流卷气，形成气孔；如果过慢，牙孔区域充填时间过长，铝液降温，可能导致充填不完整，气体无法排出，同样形成气孔。因此，需要根据牙孔区域的结构优化高速速度，避免卷气且保证充填完整。

- 卷气: 慢速行程短意味着高速起点早，金属液过早进入高速阶段。这可能导致铝液在压射室内停留时间不足，温度较高，但同时也可能因高速过早引起卷气。如果卷气产生的气体最终聚集在牙孔区域，就会形成气孔；而缩孔增多则可能是因为高速过早导致填充模式变化，使牙孔区域补缩不足。实际上，慢速行程应与慢速速度匹配，保证金属液平稳推进到内浇口。
