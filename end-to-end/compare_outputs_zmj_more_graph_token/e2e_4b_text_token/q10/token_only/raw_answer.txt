【溯源分析】
1. 当前样本把牙孔区域作为特殊区域，说明该区域需要把热节和气体风险放在一起判断。一般区域可以反映缺陷在样本中出现的频次，但牙孔区域还需要看局部充型和冷却状态，不能只按一般分布推测。
2. 快速速度决定金属液进入型腔的急缓，建压时间决定压力传递和补压效果，铸造压力决定最终补压强度。三者共同决定缺陷是否能被有效压闭。高速速度、建压时间和铸造压力的改变会同时影响充填前沿和补压状态，不能只看某一项参数。
3. 一般区域可以作为缺陷分布范围的参考，但牙孔区域需要把高速充型、局部冷却和铸造压力链放在一起判断，优先关注局部热节和气体风险。

【建议方向】
1. 先用同料号、同模次或相近工况样本对照，观察牙孔区域缺陷是否集中，确认是局部结构问题还是参数波动放大了风险。
2. 再用连续样本或相近缺陷样本对照，判断参数变化时缺陷是增多、减少还是局部集中，把参数调整与缺陷分布变化对齐。
3. 后续验证应关注高速速度、建压时间、铸造压力和局部冷却的联动变化，而不是只调整某一项参数。
