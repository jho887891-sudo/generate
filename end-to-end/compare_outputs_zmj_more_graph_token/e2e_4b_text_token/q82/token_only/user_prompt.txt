四、检索文本：
- 高速行程: 正常。高速行程决定了金属液开始高速填充的位置，直接影响气体的聚集区域。当高速起点改变时，气体被推动的路径和最终位置也会改变，因此集中性气孔的位置会相应移动。这正是通过调整高速行程将气体引入溢流槽的理论依据。现场可以逐步调整高速起点，观察气孔位置变化，找到最佳设置。
- 牙孔区域: 直接影响。牙孔区域通常需要足够的铸造压力来压实补缩。如果铸造压力不足，该区域在凝固时无法得到有效补缩，就会形成缩孔。但前提是压力必须能在内浇口凝固前传递进去，否则压力再大也无用。
- 卷气: 鼓泡是皮下气孔在热处理时气体膨胀所致。原始铸件皮下有密集气孔，加热后气体压力将表层顶起。需减少铸件含气量，加强除气，控制慢速卷气，并适当降低热处理温度。
- 排气: 铜含量高，合金流动性好，有利于排气，减少卷气孔。但铜含量过高，热裂倾向大。需综合权衡。
- 线状气孔可能由模具裂纹引起，气体沿裂纹进入。需检查模具是否有裂纹，及时修复。也可能是沿顶杆间隙的气体通道。
- 氢气在凝固过程中均匀析出: 分散性气孔通常由两种原因引起：一是铝液本身含气量高，氢气在凝固过程中均匀析出；二是慢速阶段卷气，气体均匀混入铝液。前者气孔细小且多呈圆形，后者气孔略大且可能形状不规则。应先检查铝液质量，加强除气除渣；再优化慢速速度，避免压射室卷气。
- 氢气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 临界速度: 具体需根据压射室直径计算临界速度。目的是确保金属液在压射室内平稳上升，避免湍流卷气。同时，应结合慢速行程，保证金属液在到达内浇口前温度合适。
- 气体: 镶件周围常有间隙，气体可能积聚。预热镶件可减少气体。同时，调整高速起点，使镶件处充填平稳，避免卷气。检查镶件涂层是否产生气体。
- 气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
