【结论】当前样本应优先把牙孔区域的建压问题与高速行程、高速时间、建压时间和铸造压力联动起来，而不是只看铸造压力或只看高速速度。当前主导风险更偏向牙孔区域的内腔补压不足，而不是单纯判断铸造压力或浇道卷气。

【溯源分析】
1. 重点区域是牙孔区域，该区域对建压及时性最敏感，一旦凝固或建压不及时，缺陷会快速扩展。当前样本的区域证据是牙孔区域，说明该区域需要把建压响应作为比其他区域更高优先级。
2. 参数链是高速行程= 205 → 高速时间 46 → 建压时间 114 → 压射压力 316 → 铸造压力 926。高速行程决定高速充型覆盖范围，建压时间决定压力传递时序，两者都影响牙孔内腔能否及时补压。
3. 区域风险是牙孔内腔补压风险，参数链是高速行程 → 建压时间 → 压射压力 → 铸造压力。当前样本的区域风险不能脱离高速充型和建压时序来判断，只靠压力大小或只靠铸造压力不能解决内腔补压不及时问题。

【建议方向】
1. 先固定高速行程，观察高速充型范围是否稳定，再判断后续参数调整是否能改善。
2. 用同料号、同模次或相近工况样本对照，观察牙孔区域缺陷是否随高速行程或建压时间变化而变化。
3. 后续验证应关注高速行程稳定后，建压时间、压射压力和铸造压力是否同步改善，形成可复现的工艺收敛。
