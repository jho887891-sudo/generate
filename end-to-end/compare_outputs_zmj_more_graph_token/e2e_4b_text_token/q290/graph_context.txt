四、检索文本：
- 高速速度: 高速时间由高速行程和高速速度决定，射料结束位置是高速的终点。因此，结束位置固定时，高速时间取决于高速速度和起点。调整结束位置会影响高速行程，从而影响高速时间。
- 射料结束位置: 射料结束位置决定了最终留在压室内的料饼厚度。位置太靠前意味着料饼过薄，无法为铸件提供足够的补缩压力。牙孔区域往往需要后期压力压实，一旦压力中断，该区域就会产生缩孔。此外，薄料饼还可能导致建压时间延长，进一步削弱补缩效果。现场应逐步后移结束位置，增加料饼厚度，观察缩孔改善情况。
- 慢速速度过快: 有影响。慢速速度决定了金属液在压射室内的平稳程度。如果慢速过快导致卷气，这些气体会随金属液进入型腔，最终可能分布在包括焊接区域在内的各个部位。焊接时气体受热膨胀，形成焊接气孔或焊缝缺陷。因此，控制慢速速度是减少焊接区域气孔的基础措施之一。
- 高速速度直接影响金属液的充填模式和流动前沿的稳定性。速度过快会导致喷射卷气，使气体进入焊接区域；速度过慢则可能使焊接区域充填时温度过低，产生冷隔或氧化夹杂，焊接时这些缺陷会暴露。因此，高速速度应优化到既能快速充满型腔，又不产生湍流，确保焊接区域质量。
- 缩孔: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 卷气: 湿度高时，应适当降低慢速速度，以减少卷气带入水汽。同时，加强铝液除气，并考虑在模具上增加排气。但慢速速度也不能过慢，以免铝液降温。
- 两者乘积固定时，可相互调整。例如，缩短高速行程同时提高高速速度，可保持高速时间不变。但需注意高速速度是否超限，高速行程是否合理。优化时应优先保证高速速度在安全范围。
- 气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 气体: 螺纹镶件常有间隙，气体可能积聚。预热镶件可减少气体。同时，优化该区域填充，避免卷气。检查镶件是否含油或污染物。
