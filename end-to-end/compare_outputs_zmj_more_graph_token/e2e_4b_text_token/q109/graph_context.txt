四、检索文本：
- 预结晶: 铝温高时，可适当降低慢速速度，因流动性好，不易预结晶；铝温低时，需提高慢速速度，减少温降。但慢速速度受临界值限制，不能过高，需平衡。
- 补缩压力传递: 料饼厚度直接影响补缩压力传递。如果料饼太薄，牙孔区域缩孔面积会增大；如果料饼合适，压力能有效传递，缩孔面积减小。因此，料饼厚度是影响牙孔区域缩孔面积的关键参数之一。
- 流动性好: 铝温高时，可适当降低慢速速度，因流动性好，不易预结晶；铝温低时，需提高慢速速度，减少温降。但慢速速度受临界值限制，不能过高，需平衡。
- 经验公式：高速起点 = 料饼厚度 + 浇注系统体积对应的行程。浇注系统体积包括直浇道、横浇道、内浇口。计算后通过试模修正。
- 料饼太薄: 射料结束位置通过料饼厚度影响整体致密度。如果料饼太薄，铸件疏松，焊接区域也可能疏松，焊接时气体逸出形成气孔。如果料饼合适，压力传递好，焊接区域致密，气孔少。因此，保证合适的结束位置有助于焊接质量。
- 慢速速度: 铝温高时，可适当降低慢速速度，因流动性好，不易预结晶；铝温低时，需提高慢速速度，减少温降。但慢速速度受临界值限制，不能过高，需平衡。
- 料饼厚度影响整体致密度。如果料饼太薄，铸件补缩不足，内部疏松，焊接区域也可能疏松，焊接时气体逸出形成气孔。如果料饼合适，铸件致密，焊接区域气孔少。因此，保证料饼厚度是控制焊接质量的因素之一。
- 高速起点: 高速行程 = 结束位置 - 高速起点。结束位置固定时，高速起点决定行程。
- 温度过高: 浇口套冷却不足，温度过高，浇口凝固慢，但可能使金属液过热，增加吸气，同时影响脱模。需加强浇口套冷却，保持合适温度。
- 卷入气体的方式: 慢速速度影响卷入气体的方式。慢速过快，气孔多而小，呈分散状；慢速适中，气孔少；慢速过慢，可能产生大卷气团。因此，慢速影响气孔大小和分布。
