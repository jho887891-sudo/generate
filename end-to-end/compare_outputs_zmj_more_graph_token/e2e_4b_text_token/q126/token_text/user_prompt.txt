- 湿度高: 壁厚突变处形成热节，凝固时收缩无补缩来源，产生集中缩孔。厚大区域最后凝固，若压力不足，缩孔严重。设计时应尽量均匀壁厚，4. 铝液精炼除气不彻底，会产生什么类型的气孔？      除气不彻底导致铝液含氢量高，凝固时析出细小分散的氢气孔，探伤呈针孔状或星点状，常见于厚大区域。需加强精炼工艺，使用旋转除气或氮气吹洗，控制含氢量。
- 慢速速度过快: 有影响。慢速速度决定了金属液在压射室内的平稳程度。如果慢速过快导致卷气，这些气体会随金属液进入型腔，最终可能分布在包括焊接区域在内的各个部位。焊接时气体受热膨胀，形成焊接气孔或焊缝缺陷。因此，控制慢速速度是减少焊接区域气孔的基础措施之一。
- 铝液: 增加高速速度可缩短填充时间，减少铝液温降，有利于补缩，从而减小缩孔。但速度过快可能卷气，需平衡。通常在不引起喷射的前提下，适当提速对缩孔有益。需监控气孔变化，防止顾此失彼。
- 高速起点: 单个大气孔多由卷气团或涂料残留引起。检查该位置是否最后填充，气体聚集；或模具该处有凹坑存留气体。调整高速起点，避免气体聚集；检查模具表面；加强排气；确保脱模剂喷涂均匀。
- 最后填充: 首先应确定焊接区域在充填过程中的位置。如果是最后填充区，则可能是气体聚集导致；如果是热节区，则可能是缩孔或气缩孔。排查参数包括：检查高速起点是否将该区域设为最后填充，调整高速速度避免卷气；检查排气槽是否有效；检查铸造压力和建压时间是否足够压实该区域；检查铝液含气量是否过高。通过逐步调整这些参数，观察焊接区域缺陷变化。
