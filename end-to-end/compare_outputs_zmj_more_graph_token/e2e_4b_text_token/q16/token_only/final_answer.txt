【结论】当前样本应优先按气孔数量主导区域判断风险，把出现次数最多、分布范围最广的区域作为当前主导风险来源。

【溯源分析】
1. 区域证据只反映气孔在空间分布上的集中区域，数量多或连续出现时应优先判断为工艺放大区域。当前样本把气孔分布集中到慢速行程= 525 附近，说明慢速阶段的卷气或排气不畅可能把气孔带入高速阶段。
2. 参数链是高速充型、建压、铸造压力与气孔之间的直接作用链。高速行程为 205，高速时间为 46，建压时间为 114，若高速不稳或建压不及时，气体无法及时前移，反而会把气孔带入后续阶段。
3. 不能只看气孔单点，还要看参数链是否把气孔与高速、建压、铸造压力放在一起调节。当前样本的气孔风险不能只按数量多少排序，还要看慢速阶段是否把气体带入高速，以及高速后参数调整是否能打断气孔传播。

【建议方向】
1. 先固定其他参数，单独观察慢速行程或慢速时间变化时气孔分布是否收敛。
2. 用同料号、同模次或相近工况样本对照，观察气孔空间分布与参数变化是否一致。
3. 后续验证应关注高速行程、高速时间、建压时间连续调整后，气孔分布是否从慢速阶段前移或减少。
