四、检索文本：
- 模具温度: 模具温度高的区域凝固慢，成为热节，缩孔易在此处形成。若冷却系统设计不当，热节温度过高，补缩需求大，易产生集中缩孔。需优化冷却水道，使模温均匀。
- 致密度: 说明气孔源于铸件本体。需返回压铸工序，优化该区域质量：调整高速起点，使焊接区避开气体聚集；加强冷却，提高致密度；控制铝液含气量。必要时改用低气孔率合金。
- 铸造压力: 铸造压力直接影响铸件的致密度。较高的铸造压力可以使焊接区域的组织更致密，减少微观缩松，从而降低焊接时气体逸出的风险。但铸造压力不能解决卷气问题。如果焊接区域本身有气孔，压力只能压缩而不能消除。因此，需要结合其他参数共同优化。
- 产生气孔: 粗糙表面易粘铝，脱模时拉伤，产生气孔。同时气体易在凹坑处积聚。需抛光模具表面，提高光洁度。
- 高速行程: 查看压射曲线中高速段是否平稳，有无波动。波动说明填充不稳定，易卷气。同时检查建压时间是否过长，导致疏松。根据曲线调整高速速度和建压时间，使填充平稳。
- 铸件致密度: 有一定改善作用。较高的铸造压力可以将部分微小气孔压缩变小，甚至使气孔闭合，从而提高铸件致密度。但压力不能消除气孔产生的根源，因此改善程度有限。如果气孔很大或很多，单纯依靠压力无法根治，仍需从源头上减少气体卷入。
- 高速行程与浇口厚度无关，但浇口厚度影响补缩，间接影响高速起点的选择。厚浇口允许稍晚高速，因补缩通道持久。
- 缩孔位置: 压力大，缩孔深度浅，甚至消失；压力小，缩孔深。通过压力可控制缩孔在铸件内的位置，但根本消除需足够压力。
- 卷气: 可能。料饼过厚虽然有利于补缩，但如果压射室填充率过低，金属液在压射室内的自由表面过大，反而容易卷气。此外，过厚的料饼可能意味着射料结束位置太靠后，导致高速行程变短，改变了填充模式，也可能引起气孔。因此，料饼厚度并非越厚越好，应根据压室直径和铸件重量优化填充率。
- 循环周期影响模具温度，进而影响焊接区域的凝固速度和气体排出条件。如果周期过短，模温过高，焊接区域可能过热，气体溶解度降低，析出气孔；如果周期过长，模温过低，可能导致焊接区域充填不良或冷隔，焊接时出现缺陷。因此，保持稳定的循环周期和模温对焊接质量至关重要。
