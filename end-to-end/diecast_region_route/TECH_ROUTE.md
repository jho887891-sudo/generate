# 多模态大模型前期整条技术路线

## 1. 总目标

把你当前的串联系统：

`X光图 -> YOLO -> 结构化摘要 -> LLM -> 图谱辅助`

拆成两层：

### 第一层：多模态主模型（训练得到）
输入：
- X 光图
- 工艺参数
- 问题
- 区域先验（来自模板匹配 + mask 约束）

输出：
- 结论
- 溯源分析
- 建议方向

### 第二层：图谱约束层（推理后置）
输入：
- 当前样本结构化信息
- 问题
- 多模态主模型初步语义

输出：
- 图谱证据
- 证据约束下的最终回答

---

## 2. 为什么训练阶段先不接图谱

图谱在你的任务里不是为了替代分析，而是为了：
- 约束回答
- 抑制幻觉
- 提供外部可追溯证据

所以图谱更适合做**后置约束层**。

训练阶段只做：
- 视觉理解
- 区域感知
- 参数理解
- 语言生成

推理阶段再做：
- 图谱检索
- 证据注入
- 证据一致性约束

---

## 3. 区域划分怎么保留

你现在的区域划分来源于：
- 视角模板
- SIFT/模板匹配
- mask warp
- 缺陷中心点落区

这本质上是强工业先验，不建议丢掉。

训练时不让模型重新学区域边界，而是把这套结果显式注入模型：

### 3.1 缺陷级区域 token
每个 defect token 带：
- ROI 视觉特征
- 区域 ID
- 视角 ID
- 坐标
- 面积
- 等效直径
- IsPore

### 3.2 区域级 summary token
每个区域再给一个 summary token，带：
- count
- max_area
- max_diameter

### 3.3 全局文本摘要
保留你现有 summary 文本继续进 prompt。

---

## 4. 训练分三阶段

### 阶段 A：视觉-区域对齐
- 冻结 YOLO
- 冻结大部分 LLM
- 训练 projector / region_prior / param_encoder
- 目标：让视觉 token 和区域先验能进入语言空间

### 阶段 B：多模态指令微调
- 输入：图像 + 参数 + 问题
- 输出：三段式回答
- 继续训练 projector + region_prior + LLM adapter

### 阶段 C：轻量联合微调（可选）
- 小学习率解冻 YOLO 后几层
- 让视觉特征更贴近压铸诊断

---

## 5. 推理阶段图谱怎么接

1. 多模态主模型先看图，得到初步回答
2. 再根据 summary + question 走 Neo4j 检索
3. 把图谱证据文本插回 prompt
4. 让 LLM 在证据约束下重答一次

这一步不改变主模型训练，只增加推理可靠性。

---

## 6. 这版代码的核心定位

这版代码解决的是：

**“先把 YOLO + 区域先验 + LLM 训练成一个区域感知多模态主模型，再为后置图谱约束预留接口。”**

不是最终上线系统，但正好适合你现在先验证：
- 数据能不能顺
- 模型能不能 forward
- prefix token 方案能不能跑
- 二次微调 LLM 能不能继续多模态适配
