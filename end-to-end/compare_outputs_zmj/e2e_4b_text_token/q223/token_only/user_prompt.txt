三、检索文本：
- 建压时间延长: 氮气压力降低，增压器响应变慢，建压时间延长，导致补缩失效，缩孔增加。需立即补充氮气至规定值，并检查是否有泄漏。定期检查氮气压力是日常维护重点。
- 气孔: 微小波动一般不会直接导致气孔，但若波动频率高，可能引起液面轻微扰动，长期积累可能增加卷气风险。更重要的是检查波动原因，避免波动在高速段放大。稳定慢速有助于减少初始卷气。
- 流动性: 锰含量升高，可能形成金属间化合物，影响流动性，间接增加卷气孔风险。但锰主要改善力学性能，对气孔直接影响小。需控制锰在合金标准内，避免过量导致脆性相。
- 建压时间: 建压时间波动导致补缩效果不一致，铸件缩孔时有时无，质量不稳定。原因可能是液压油粘度变化、氮气压力波动、或阀响应异常。需检查液压系统，保持油温稳定，定期维护。
- 建压时间长，缩孔可能更深（远离浇口），因压力无法传递到深处。建压时间短，缩孔浅，甚至消失。因此，控制建压时间可改变缩孔位置。
- 蜂窝状缩孔是严重缩松，需大幅提高铸造压力，缩短建压时间，加强冷却。同时考虑改变合金成分，减少凝固范围。
- 夹杂: 微量元素如铬、钒、镍等，在低含量时对气孔无直接影响。但若超标形成夹杂，可能成为气孔核心。需控制合金成分符合标准，避免有害杂质超标。
- 缩孔: 氮气压力波动导致建压时间不稳定，缩孔时有时无。
