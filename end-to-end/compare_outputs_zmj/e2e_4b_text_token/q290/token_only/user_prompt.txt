三、检索文本：
- 缩孔: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
- 气孔: 优先检查高速行程和排气系统。因为大面积气孔往往是气体聚集所致，需确认牙孔区域是否是最后填充区，气体是否被推到这里。调整高速起点，让气体在到达牙孔前进入溢流槽。同时检查排气槽是否堵塞或设计不足。如果气孔是氢气孔，则还需检查铝液含气量。
- 流动性变差: 硅含量过高，初晶硅粗大，流动性变差，补缩困难，缩孔增加。同时热裂倾向大。需控制硅含量在共晶点附近。
- 高速速度: 高速时间与高速速度成反比，与高速行程成正比。在高速行程固定时，速度越快，时间越短；反之越长。
- 高速速度下降，填充时间延长，铝液降温，可能导致补缩通道提前凝固，缩孔增加。需检查液压系统、氮气压力，恢复速度。轻微下降可能影响不大，但需监控，避免持续恶化。
- 铝温高: 铝温影响晶粒度和缺陷。温度高，晶粒粗，缺陷多，疲劳寿命低；温度低，晶粒细，但可能有冷隔，也降低寿命。需控制最佳温度。
- 卷气: 高速填充阶段对气孔影响最大。该阶段金属液快速进入型腔，若速度不当易卷气。慢速阶段影响初始含气量，增压阶段影响缩孔。因此，高速参数是控制气孔的关键。
