三、检索文本：
- 牙孔区域: 湿度高导致铝液含氢量增加，氢气在凝固时析出，如果牙孔区域是最后凝固或局部热节，氢气会聚集形成气孔。加工后这些气孔暴露，影响螺纹强度。因此，高湿度环境下，牙孔区域气孔风险增大，需加强除气和排气。
- 会优先在最后凝固的厚大区域析出并聚集: 湿度高时，铝液吸氢严重，氢气在凝固过程中溶解度降低，会优先在最后凝固的厚大区域析出并聚集，形成集中性氢气孔。这些气孔往往与缩孔混合，形成气缩孔，加剧缺陷严重性。因此，在高湿度环境下，厚大区域更容易出现气孔，需要加强除气、排气和冷却。
- 形成气孔: 铝液温度越高，氢气溶解度越大。凝固时溶解度骤降，过饱和氢气析出形成气孔。因此，高温铝液易产生氢气孔。控制铝液温度在工艺下限，并加强除气，可减少氢气孔。
- 气孔: 稀土元素有净化、细化作用，可减少气孔。但过量可能形成稀土夹杂。适量添加可改善铸件质量，需试验确定。
- 加强铝液除气: 湿度高时，应加强铝液除气，适当降低浇注温度以减少吸气，优化慢速速度减少卷气，并在模具上增加排气槽或溢流槽。同时，保持脱模剂喷涂量适中，避免过多水分。
- 致密度降低: 湿度高导致气孔增多，降低致密度，从而降低强度和延伸率。尤其是氢气孔，
