- 初始含气量: 慢速速度影响初始含气量，但集中位置由高速段决定。慢速卷气产生的气体总量多，集中气孔可能更严重；反之则轻。因此，控制慢速速度是减少集中气孔总量的基础。
- 冷隔: 铝液温度高时，缩孔通常较大且不规则，因凝固时间长、收缩量大；温度低时，缩孔较小但可能伴随冷隔。高温缩孔多集中在最后凝固区，低温缩孔可能更分散。需根据缺陷调整温度。
- 气孔: 氧化夹杂物密度与铝基体差异小，探伤图上影像模糊，无清晰边界，呈云雾状或絮状；气孔边界清晰，呈圆形或椭圆形。夹杂物常与气孔伴生，成为气孔核心。可通过金相验证，加强铝液过滤和除渣。
